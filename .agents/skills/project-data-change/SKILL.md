# 按规范做数据变更

## 输入与必读

输入为变更名、实体/副本范围、目标环境和迁移/清理授权。读取[AGENTS.md](../../../AGENTS.md)、变更场景/设计/tasks、现有字典和迁移，以及[数据](../../../docs/standards/07-数据规范.md)、[后端](../../../docs/standards/02-后端开发规范.md)、[安全](../../../docs/standards/03-安全开发规范.md)、[运维规范](../../../docs/standards/05-部署运维规范.md)。

## 执行

1. 列出归属链、外键/唯一约束、审计、留存及全部副本，检查是否含问答/测验来源快照、执行记录、缓存和备份；同步唯一数据字典。
2. 创建只增迁移和明确回退方案，解释旧版兼容、既有数据影响和重跑行为；使用扩展→迁移→收缩，不清库升级，不改已执行迁移。
3. 在隔离合成测试环境执行迁移、重跑和回退，核验数据值、归属和并发约束。数据库事务外处理文件、向量及其他外部副作用。
4. 在写入/删除中途注入可恢复失败，检查任务记录、权限先收紧、重试幂等和最终收敛；恢复正确流程并清理测试副本。
5. 验证备份恢复后接流量前重放删除清单；核验不可恢复或破坏步骤有实际授权及可用备份，发布流程另按版本技能执行。

## 停止条件

缺 schema、字典、迁移/回退、独立测试环境或恢复依据时，报告缺项，不造演练结论。未经明确授权不得对生产执行删除/迁移、清空数据或回滚；已获授权的范围内工作不重复索取批准。

发现遗漏副本、越权、重复正式结果或不可回退迁移时停止该变更，先修复和评审，不接受静默缩小验证范围。

## 输出证据

在 `docs/changes/<变更名>.md` 记录结构和字典差异、实际命令/退出码、测试值与约束、迁移/回退/重试、删除副本及恢复结果、剩余风险；失败与未执行分开，不含真实生产数据。
