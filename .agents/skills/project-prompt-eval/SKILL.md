# 改提示词并跑评测

## 输入与必读

输入为变更名、待改模板/模型/参数、前后版本和适用评测集。读取[AGENTS.md](../../../AGENTS.md)、变更场景及[AI规范](../../../docs/standards/06-AI应用规范.md)、[测试规范](../../../docs/standards/04-测试规范.md)、[安全规范](../../../docs/standards/03-安全开发规范.md)。

## 执行

1. 确认生成与确定性规则的边界，读取当前生效模板、修订、适配器、模型参数及评测脚本，记录基线版本；不能只在对话里修改线上提示词。
2. 固定数据、模型标识、温度、召回参数和评价规则，使用非生产资料。调参集与最终评价集分开，不能先看最终失败样例再当作独立结果。
3. 先跑基线再做范围内修改，执行相同正向、无证据拒答、跨班、伪引用、注入及畸形输出回归；工具通过业务服务授权，候选题仍须教师审核。
4. 比较答案依据、引用有效性、拒答、安全、耗时和用量；语义变化按标注依据判断，不能只匹配固定措辞。失败样例保留，不筛掉后宣称通过。
5. 关联新模板/模型版本、参数、修改理由和前后结果，提交人工评审。课程30题效果实验按 AI 规范另记，不能与工程回归混为已达标。

## 停止条件

缺模板、适配器、模型授权、评测数据/命令或运行环境时，停止运行并报告具体缺项，不造请求和评测结果。外部调用只在当前授权与额度内进行；不得盲目重试有副作用工具。

安全或出处回归失败阻断交付，不降低阈值或修改标签掩盖；确需改变标准先走规范评审。

## 输出证据

结果未来放 `docs/eval/YYYY-MM-DD-<版本>.md`，在 `docs/changes/<变更名>.md` 关联前后配置、实际命令、退出码、样本数量、指标、失败原因和未执行项；不记录凭据或学生原文。
