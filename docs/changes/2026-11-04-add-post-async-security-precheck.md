# 第 8 课异步任务收尾安全自查规约

## 变更说明

按[第 8 课任务清单](https://devops.hello1023.com/课程任务清单-第8课.html)起草[独立 OpenSpec 变更](../../openspec/changes/2026-11-04-add-post-async-security-precheck/proposal.md)。细化课程 SEC-01–07、资产检查入口、脱敏归档和复验条件，复用异步变更的并发及事务证据。

- `openspec-propose` 的输入为课程清单和异步任务收尾自查。读取 AGENTS、README、OpenSpec 配置、异步变更提案与任务、相关授权和技能契约，以及 Makefile 和已有扫描脚本。按 CLI 依赖顺序生成 proposal、spec、design、tasks。
- `project-review` 的输入为新变更及四份规划产物。对照安全、评审和相关工程规范，检查课程覆盖、判定口径、上游证据分工及后续任务状态。

- 本次修订用 `openspec-update-change` 读取四份既有规划产物，以用户贴出的正式清单为验收输入，将 SEC-01–07 改为可独立定位的条款，并同步提案、设计和任务。用 `project-review` 复核三段式、固定报告路径、原始红项保留和仓库门禁边界。
