# 各课 OpenSpec 生成提示词自检

## 变更说明

按用户授权交付[各课 OpenSpec 生成提示词](../openspec-course-prompts.md)。先按第 7 课完成运行骨架，再在本仓库重新建设第 3–6 课功能，第 8 课接入队列并完成题库、测验、错题、看板。第 7 课保留已交付的规范变更及其历史，使用独立的骨架提示词补齐缺口。用户本轮要求先完成提示词，实际 change 生成、提交与应用实施分别属于后续步骤。

选题扩展依据为[选题说明](<../../选题说明(1).pdf>) §3.2–3.3、§4.2–4.4、§6。课件依据为提示词各节链接的实践与验收、正式任务清单、专题页及学期项目说明。第 8 课采用异步客观题评分作为拟议课程映射，AI 候选题生成和后台索引复用同一队列契约；RabbitMQ 为暂拟选型。客观题评分映射、模型批改和教师改分的差异需教师确认。
