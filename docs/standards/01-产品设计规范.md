类别：五类必修。适用：未来 HTML 模板、CSS、原生 JavaScript 页面、组件、文案及需求变更。读取时机：页面与交互变更前；入口见 [AGENTS.md](../../AGENTS.md)。

下表记录页面的最小信息架构及实施状态。登录、资料和教师工作台的已接入项指认证与资料开发候选，代码交付状态见[对应变更](../../openspec/changes/2026-11-04-add-class-auth-material-ingest/tasks.md)。用户与场景概述维护在 [README](../../README.md)。

## 规则

| 编号 | 规定 | 原因 | 检查动作 | 失败判据 |
| --- | --- | --- | --- | --- |
| PROD-01 | 每条能力标明用户、触发操作，并映射到页面清单 | 避免无入口需求 | 本次对照 README 场景和清单 | 有场景无页面或角色不明 |
| PROD-02 | 功能入口唯一，新增路由同步清单；未知路径返回 404 | 稳定导航 | 本次查入口列；实现后逐路由访问 | 孤立页面、清单外入口或未知路径误成功 |
| PROD-03 | 每个数据视图实现四状态，检索无命中单独提示 | 防止空白和无限加载 | 本次查模板；实现后清数据、断依赖 | 无状态提示或错误不结束 |
| PROD-04 | 使用下列受控术语，扩展先登记 | 保持概念一致 | 本次全文核对；实现后查同屏文案 | 同概念多种名称 |
| PROD-05 | 常规字段失焦与提交校验；提问仅提交校验，必填有标识 | 避免噪声和遗漏 | 实现后空值、失焦、提交走查 | 错误远离字段或提交后才知必填 |
| PROD-06 | 提交期间禁用重复触发，后端仍须保证幂等 | 防止重复副作用 | 实现后连点、重放请求 | 多条正式结果或永久禁用 |
| PROD-07 | 复用基础组件和视觉令牌，新增组件先登记 | 防止样式漂移 | 本次查组件表；实现后新增一页复核 | 自造间距、字号或重复组件 |
| PROD-08 | 错误提示包含现象、可能原因、下一步 | 让故障可处理 | 本次抽查模板；实现后故障注入 | 只有“系统错误”或无下一步 |
| PROD-09 | 控件关联标签、焦点可见，信息不只靠颜色；正文对比度至少 4.5:1 | 保证可达性 | 实现后键盘和对比度走查 | 主路径不可达或标签缺失 |
| PROD-10 | 流程先定义状态、转移和允许操作，由服务端校验 | 防止前端越过规则 | 实现后提交非法目标状态及并发操作 | 已终结记录被覆盖或静默抢写 |
| PROD-11 | 批量导入先校验预览再确认，整批原子执行；导出授权脱敏并留痕 | 避免半批和泄露 | 实现后混入一条非法记录 | 部分生效、无行号原因或越权导出 |
| PROD-12 | 产品变更同步 README、页面清单及变更记录 | 追溯入口演变 | 每次评审对照差异 | 实现与清单不一致 |

## 四状态文案模板

| 状态 | 模板 | 操作 |
| --- | --- | --- |
| 加载中 | 正在加载{对象}，请稍候。 | 保留布局，允许离开；有界超时后进入错误态 |
| 正常 | 已显示{数量}条{对象}。 | 展示真实结果及权限内操作 |
| 错误 | {对象}加载失败，可能是{可公开原因}。请重试；仍失败请提供请求标识。 | 重试和返回；不暴露堆栈 |
| 空状态 | 暂无{对象}。你可以{权限内下一步}。 | 教师可创建；学生可调整范围或联系教师 |
| 检索无命中 | 资料中未找到相关内容。请更换关键词，或联系本班教师补充资料。 | 不编造出处，不冒充依赖错误 |

## 术语与视觉基线

| 面向用户 | 技术标识 | 不混用 |
| --- | --- | --- |
| 资料 | `material` | 文档；文件仅指上传附件 |
| 切片 | `chunk` | 分片、段落 |
| 出处 | `citation` | 来源链接等任意替代词 |
| 班级 | `class` | 租户、机构 |
| 章节 | `chapter` | 跨班课程、选课 |
| 会话 | `session` | 执行记录；二者权限与用途不同 |
| 执行记录 | `application_run` | 运行日志 |
| 候选题/题目 | `question` | 已发布测验 |
| 测验 | `quiz` | 作业、考试混称 |
| 作答草稿/正式提交 | `submission` | 自动保存等同正式提交 |
| 未解决 | `unresolved` | 无反馈等同未解决 |

间距令牌为 4/8/16/24/32，字号为正文 16、小标题 20、页面标题 28；是拟用 CSS 令牌值，不代表样式已实现。语义色只表达成功/警告/错误，并附文字；具体配色首次视觉评审确定，达不到对比度不得合并页面。

组件清单：按钮、输入及校验提示、上传、列表/表格、分页、状态提示、代码块、出处卡片、确认框。窄屏小于 768px 单列；宽屏至少 768px 可双列。表格局部滚动，不让主操作离开屏幕。

接口试调组合复用既有选择框、输入、按钮、状态提示与代码块；长路径选择框限制在容器宽度内。共用样式入口为 `app/templates/_page_styles.html`。本次入口新增用于 Task 5.1，不迁移既有业务路径；未知路径继续404，具体请求仍走原业务授权。
