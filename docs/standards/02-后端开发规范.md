# 后端开发规范

类别：五类必修。适用：未来 Flask 服务端、SQLAlchemy 数据访问、HTTP 契约和外部适配器。读取时机：服务端或接口变更前；授权另见[安全规范](03-安全开发规范.md)。以下为待实现约定。

## 分层与契约规则

| 编号 | 规定 | 原因 | 检查动作 | 失败判据 |
| --- | --- | --- | --- | --- |
| BE-01 | 接口层→业务层→数据访问层；模型、Qdrant、HTTP/MCP 由外侧适配器实现 | 限制改动影响 | 实现后检索查询和客户端调用位置 | 反向依赖、路由直接查库或业务直接调外部 SDK |
| BE-02 | 资源路径用 `/api/v1/`、小写复数；HTTP 方法符合读写语义 | 统一调用方式 | 本次核对约定；实现后查路由表 | 第二套前缀、GET 写数据、动词充当顶层资源 |
| BE-03 | 全部业务 JSON 走同一外层结构；错误码在本文件登记 | 避免调用方分支 | 实现后抽一读一写及其失败响应 | 字段缺失或绕过统一封装 |
| BE-04 | 接口边界校验结构/长度/范围/枚举，业务层校验状态、归属和一致性 | 及早拒绝且保留业务约束 | 实现后缺必填及非法状态请求 | 未校验进入持久化或业务层承担 HTTP 解析 |
| BE-05 | 查询只在数据访问层；事务由业务层界定，迁移可重跑并有回退 | 明确原子性 | 实现后查 ORM/SQL、重跑与回退迁移 | 跨层查询、半笔业务或不可解释回退 |
| BE-06 | 事务内不得 HTTP、模型、消息投递、文件上传或长计算；外部副作用用事件/Outbox 补偿 | 外部操作不可回滚 | 实现后在事务中制造失败 | 副作用残留且无状态记录/重试责任 |
| BE-07 | 每个写接口声明幂等；重复与并发由存储唯一约束兜底 | 避免检查后写入竞态 | 实现后并发重放同一业务键 | 重复成绩、重复索引版本或重复工具副作用 |
| BE-08 | 分页/排序/筛选参数统一并走白名单 | 控制查询范围 | 实现后传未知字段和超上限分页 | 无上限拉全量或拼接任意字段 |
| BE-09 | 非唯一排序键后追加主键作为稳定兜底 | 防止跨页重复遗漏 | 实现后同排序值跨页核对 ID | 同一记录重复或无故消失 |
| BE-10 | 非法筛选必须明确失败，不能按未传处理；0/false 按真实值处理 | 防止退化全量 | 实现后未知字段、错类型、0/false 请求 | 非法查询返回全量或有效过滤丢失 |
| BE-11 | 地址、密钥、环境变体与开关由统一配置入口读环境变量；必填缺失启动失败 | 避免隐式配置 | 实现后逐项删必填配置启动 | 随机密钥或隐藏默认值继续运行 |
| BE-12 | 状态动作由服务端转移，终结状态不可随意改写，并发冲突明确返回 | 防止静默覆盖 | 实现后两会话处理同一版本 | 客户端指定状态即生效或后写静默覆盖 |

规划职责为 Flask 路由/输入模式、业务服务、SQLAlchemy 仓储、适配器和配置装配；源码目录由骨架变更建立，不照搬 Go 的 `backend/internal/`。

## 统一响应与初始错误码清单

业务 JSON 示例（契约示意，尚无服务）：

```json
{"code":0,"message":"成功","data":{},"request_id":"请求标识"}
```

失败时 `data` 为 `null` 或已声明的安全错误明细，不返回堆栈、答案、他人记录及凭据。每次请求有独立 request_id，不作为判断同一业务结果的比较字段。

| 业务码 | 类别 | HTTP 映射 | 公开文案及处置 |
| --- | --- | --- | --- |
| 0 | 成功 | 200/201 | 成功；数据与副作用必须符合场景 |
| 1000 | 参数不合法 | 400 | 参数不合法，请检查提示字段 |
| 1100 | 未认证/会话无效 | 401 | 登录状态无效，请重新登录 |
| 1101 | 登录失败 | 401 | 账号或口令不正确；不区分账号存在与否 |
| 1200 | 功能权限不足 | 403 | 当前账号无此操作权限 |
| 1300 | 资源不存在或不在授权范围 | 404 | 资源不存在或不可访问 |
| 1400 | 业务状态冲突 | 409 | 当前状态不允许此操作，请刷新后重试 |
| 1401 | 重复正式提交 | 409 | 已有正式提交，请查看提交记录 |
| 1402 | 已截止 | 409 | 已超过截止时间，无法提交 |
| 1500 | 外部依赖不可达/超时 | 503 | 依赖服务暂不可用，请稍后重试 |
| 1501 | 模型输出/引用无效 | 502 | 生成结果未通过校验，请重试或改用人工编辑 |
| 1600 | 限流/配额 | 429 | 请求过于频繁，请按重试时间再试 |

1000–1099 参数、1100–1199 认证、1200–1299 功能权限、1300–1399 资源隐藏、1400–1499 业务、1500–1599 依赖、1600–1699 配额。新增业务码必须先登记含义、HTTP 和下一步，禁止复用别类码。

跨班与同班他人私有资源均用 1300，与真正不存在的业务码、文案和数据相同。功能权限 1200 只用于不依赖具体资源存在性的操作。HTTP 映射和业务成功信号各自检查，不能把 HTTP 200 且业务拒绝认作放行。

文件下载、事件流、协议健康探针和网关直接拒绝可有不同体裁，但必须在对应契约登记成功信号、错误形式和请求标识；不得悄悄形成第二套业务 JSON。

## 通用参数与写入纪律

拟用 `page=1`、`page_size=20`，最大 100；超最大截到 100，非正整数拒绝。资源排序/筛选白名单在对应功能规约登记；默认 `created_at, id` 同向稳定排序。检索模式仅 `keyword`、`vector`、`hybrid`。这些为本项目约定，非案例测试结论。

写接口在对应规约声明业务键、幂等键作用域/有效期、重放结果和副作用。同一幂等键且内容一致可重放首次结果，内容不同返回冲突；同一测验同一学生另发正式提交按 1401 拒绝。唯一约束与截止校验须在事务内完成，模型不参与评分判定。

未来批量导入必须先校验并提供行号错误与预览确认，整批成功才生效；超文件/行数上限整体拒绝。具体上限由相关功能变更在实现前登记，未登记不得上线该接口。导出按权限和数据范围、集中脱敏规则执行，大批量异步并留痕。

## 检查清单与违规处理

本次执行：查分层、响应、错误码和配置约束齐全。实现后执行：一读一写接口对照层次与契约，重复/并发请求，非法筛选和必填配置缺失。事务事件由业务写入，投递器事务外执行，失败有限重试并登记待处理及补偿责任。

跨层查询应被评审发现，不通过则整改；幂等和事务违规补失败用例。规范变化同步[测试](04-测试规范.md)和[数据](07-数据规范.md)，例外按 REV-06。
