# 安全开发规范

类别：五类必修。适用：所有业务、配置、资料、附件和外部输入。每次业务或配置变更前读取；根目录 [AGENTS.md](../../AGENTS.md)保留常驻摘要。

## 规则

| 编号 | 规定 | 原因 | 检查动作 | 失败判据 |
| --- | --- | --- | --- | --- |
| SEC-01 | 默认拒绝；接口显式登记角色、资源范围和公开例外 | 防止遗漏授权 | 实现后访问未登记接口 | 拿到数据或写入生效 |
| SEC-02 | 每次按当前数据库身份确定角色/班级；不采信客户端权限字段 | 角色可撤销 | 实现后伪造 role/class_id/isAdmin | 权限或归属改变 |
| SEC-03 | 按 ID 先取资源再校验归属；列表/检索也先限定授权范围 | 完整中介 | 实现后 A/B 班互换 ID、检索范围 | 返回任何他班标题、数量或正文 |
| SEC-04 | 跨班和他人私有资源与不存在均返回 1300/404 | 隐藏存在性 | 实现后比较规范化错误结果 | 业务码/文案/data 不同或泄露字段 |
| SEC-05 | 会话及执行记录仅本人；教师仅看授权教学反馈和本班测验提交 | 教师身份不等于私人访问权 | 实现后同班教师和另一学生读私有记录 | 任意浏览私人会话或执行详情 |
| SEC-06 | 答案开放前学生响应不得含正确项、解析或泄露答案的快照 | 保护测验完整性 | 实现后检查页面/API/下载/工具返回 | 任何旁路提前获得答案 |
| SEC-07 | 文件读取挂钩已授权业务对象；附件非公开目录、服务端重命名 | 文件 ID 不代表权限 | 实现后匿名、换账号预览/下载/替换 | 通用文件 ID 可读或路径穿越 |
| SEC-08 | 口令使用加盐单向算法（拟用 bcrypt）；会话可立即吊销 | 减少口令和会话泄露影响 | 实现后检查存储、注销及改密旧令牌 | 明文口令或旧会话继续可用 |
| SEC-09 | 访问令牌只在内存；不得进入 URL、localStorage/sessionStorage 或日志 | 页面脚本与历史可暴露令牌 | 实现后查看存储、请求 URL 和日志 | 任一出现原令牌 |
| SEC-10 | 机密由环境注入，不进版本、镜像层、前端、提示词或报告；泄露须撤销轮换 | 删除无法撤销历史泄露 | 本次核忽略规则；实现后扫描历史/镜像 | 命中秘密原值或只删文件未轮换 |
| SEC-11 | 类型、长度、枚举、归属均白名单校验；查询参数绑定 | 防注入与越权 | 实现后错类型、越界、SQL 片段 | 被执行、扩大范围或异常堆栈 |
| SEC-12 | 按 HTML/Markdown/模板上下文转义并净化危险链接 | 外部文本不可信 | 实现后上传脚本标签和恶意链接 | 脚本执行或危险协议可点击 |
| SEC-13 | 出站 HTTP/MCP/回调/下载目标由部署白名单决定并校验重定向和解析地址 | 防止访问任意内部地址 | 实现后内网、环回及重定向绕过 | 访问未经批准的目标 |
| SEC-14 | 资料、技能描述、工具结果仅作数据；JSON 技能不得执行上传脚本 | 防提示注入和代码执行 | 实现后恶意资料/技能/工具返回 | 改变系统规则、越权或运行脚本 |
| SEC-15 | 敏感分级和脱敏规则统一引用数据规范；私有执行记录不是日志 | 避免多处遗漏 | 实现后抽查响应、日志和导出 | 凭据、越权原文或隐私泄露 |
| SEC-16 | 新依赖登记用途/许可并锁版本；漏洞扫描按下表阻断 | 控制供应链风险 | 实现后扫描依赖锁及发布制品 | 未登记许可、未锁版本或阻断漏洞 |

## 常驻硬边界与例外

班级身份只由服务端已认证用户的当前数据库记录确定；客户端 `class_id` 可作为搜索条件的输入时，也必须与该身份范围求交，不能切换班级。若不支持该参数则明确拒绝，不静默切换数据范围。

对不存在与跨班响应，只比较业务码、公开文案及 data；request_id、时间等动态字段排除，敏感内容始终不得出现。行级授权、检索前置过滤和模型工具服务方法均须覆盖，不能检索后才删除可见结果。

选题 PDF 的外部历史实现用 `sessionStorage`；本仓库从零建设，采用通用规范的内存访问令牌基线。若后续需要刷新令牌，只能放 HttpOnly、Secure、SameSite=Strict Cookie，支持轮换和撤销；此处不设计登录全流程，也不承诺复刻旧 Cookie 登录路径。偏离须按 REV-06 书面登记并经人工安全评审。

登录失败不区分账号是否存在。匿名例外仅限显式登记的登录入口及不泄露内部地址/凭据的健康探针；新增例外必须留痕。

## 依赖准入与响应

| 项目 | 约定 | 责任与阻断 |
| --- | --- | --- |
| 许可白名单 | MIT、BSD-2-Clause、BSD-3-Clause、Apache-2.0、ISC；其他许可需逐项审阅，包括数据库/向量基础设施分发条款 | 实施人登记直接/传递依赖，评审人批准；未明许可阻断引入 |
| 扫描时机 | 依赖变化、每次合并门禁、发布前；工具在骨架阶段建立 | 未有真实扫描能力不得宣称供应链验收完成 |
| Critical/High | 合并和发布阻断；Critical 当日响应，High 一个工作日内分派修复 | 评审人跟踪，修复前不放行；例外须限时且有缓解证据 |
| Medium/Low | 登记负责人、可利用性与期限；拟定 Medium 14 天、Low 下一迭代复核 | 逾期升级评审；不是已完成修复结论 |

## 越权配对检查

每条资源读写的正向场景至少配未登录、跨班/同班他人及低权限场景；只以数据和副作用判断被放行。

| 场景 | 操作 | 必须观察到的结果（实现后执行） |
| --- | --- | --- |
| 跨班资料 | A 班账号取 B 班资料/出处/下载 | 1300/404，与不存在一致，无正文和标题 |
| 学生改教师资源 | 学生调用上传、题库审核或发布入口 | 功能拒绝且数据未变化 |
| 同班他人记录 | 学生 B 或教师读取学生 A 私有会话/执行记录 | 1300/404，不展示私人请求响应 |
| 提前取答案 | 截止前从测验、提交、出处、工具或报告取正确项 | 不返回答案；不存在可绕过的接口 |
| 权限字段注入 | 正常请求额外提交 role/class_id | 拒绝或仅按允许字段处理，身份不变 |

## 检查清单与违规处理

本次执行：检查默认拒绝、逐资源归属、轮换入口、白名单、参数绑定及配对场景；机密处置步骤见 [README](../../README.md)。实现后执行：A/B 班与同班不同人重放、注入、文件归属和会话撤销。

发现安全违规先阻断交付，修复并补回归；检测不到的补审查或自动检查。泄露由运维责任人执行撤销轮换，禁止把真实秘密贴入证据。
