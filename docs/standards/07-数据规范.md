# 数据规范

类别：补充。适用：未来 MySQL 业务数据与正文、Qdrant、上传文件、快照、私有执行记录、缓存及备份。结构或生命周期变化前读取，使用[数据变更技能](../../.agents/skills/project-data-change/SKILL.md)。本次不设计完整表字段。

## 规则

| 编号 | 规定 | 原因 | 检查动作 | 失败判据 |
| --- | --- | --- | --- | --- |
| DATA-01 | 表名小写复数、字段 snake_case；时间 UTC 存储，枚举释义单一登记 | 减少解释差异 | 实现后比对字典与读写 | 混用时区、状态或命名 |
| DATA-02 | 主键采用一致策略，跨资源外键和级联行为明确；业务资源可直接追到班级及个人归属 | 支撑授权 | 实现后抽查归属链与跨班外键 | 孤立引用或无法校验所属 |
| DATA-03 | 业务记录带创建/更新时间、创建人；权限、审核及评分变更有只增审计 | 可追责 | 实现后重放变更追溯 | 审计缺失或覆盖历史 |
| DATA-04 | 已执行迁移只增不改、条件化可重跑；每次写回退与数据影响 | 环境可比 | 实现后干净/已迁移库重跑并回退 | 重跑破坏数据或回退无说明 |
| DATA-05 | 表和字段含义集中在未来 `docs/data-dictionary.md`，变更同步更新 | 避免多份字典 | 实现后结构与字典差异检查 | 新字段无含义或归属说明 |
| DATA-06 | 公开/内部/敏感/个人信息分级与脱敏集中在下表 | 控制数据进出 | 实现后抽日志、响应和导出 | 敏感原值跨权限暴露 |
| DATA-07 | 每类数据写留存、清理触发及责任，删除覆盖全部副本 | 防止只删一份 | 实现后到期/请求删除演练 | 任一未登记副本残留 |
| DATA-08 | 业务库、文件、向量和快照写删有序、失败有可重跑补偿 | 跨存储无共享事务 | 实现后中途失败并重试 | 无记录残留、幽灵检索或无限重试 |
| DATA-09 | 测试独立库和合成A/B班账号，不带生产未脱敏数据 | 防止调试泄露 | 实现后抽样测试数据及导出 | 真实秘密或未脱敏个人信息 |
| DATA-10 | 测验发布快照和正式结果不可被题库后改覆盖；重复正式提交有唯一约束 | 保持历史依据 | 实现后改原题、并发提交 | 历史成绩变化或产生两份正式成绩 |

主键具体类型由首个数据库变更统一确定，须在编码前写入字典，不能每模块自行选择。`class_id` 等归属字段由服务端产生；关联资源必须校验属于同一班级。

## 数据分级与暂定留存

以下是本项目的工程保留基线，非已运行清理结论。数据实施人与运维责任人须在对应功能开始前登记学期起止、具体到期时间与实名执行人；未登记不得上线持久化该类数据。

| 分级/数据 | 可见与脱敏 | 暂定留存及清理 |
| --- | --- | --- |
| 公开：帮助、规范、公开错误说明 | 可公开，不夹带运行秘密 | 随版本维护 |
| 内部：班级、资料标题、章节 | 本班授权用户；汇总不得泄露另一班数量 | 关联班级/资料生命周期，学期结束复核 |
| 敏感：资料正文、切片、原文件 | 仅授权业务正文接口返回，不进日志 | 所属学期结束后30天内清理，删除请求提前触发 |
| 个人信息：会话、反馈、执行请求响应 | 本人可见；教师只看授权教学反馈；导出匿名化 | 所属学期结束后30天内清理；来源快照一并处理 |
| 个人信息：作答、成绩、测验快照 | 学生仅本人且按答案开放规则；教师本班教学范围 | 所属学期结束后30天内清理，需延长须书面评审 |
| 账号与口令哈希 | 认证组件使用；哈希也不进入响应/日志 | 账号停用立即吊销会话，学期结束复核删除；口令重置更新哈希 |
| 审计/运行元数据 | 去内容化和最小化，主体用脱敏标识 | 暂定运行日志14天、去内容审计90天，不延长业务正文副本 |

原文仅在授权取正文和私有记录等明示契约返回，不能把“敏感字段不进响应”误用成阻止合法业务。脱敏规则：删除口令/令牌/密钥；学生标识在导出中用不可逆代号；自由文本先人工审查或不导出；小样本汇总不公开到班外。

## 副本清单与一致性

| 位置 | 可能副本 | 删除/恢复要求 |
| --- | --- | --- |
| 业务数据库 | 资料正文、记录、作答、来源元数据和审计关联 | 先标记不可访问/待清理，再按引用策略物理清理；必要去标识审计不保留正文 |
| 上传目录 | 原始 TXT/Markdown、将来可选 PDF | 按业务对象定位，不凭客户端路径；检查文件消失 |
| Qdrant | 向量、切片及出处标识 | 清除对应资料版本，查询不得命中已撤销资料 |
| 来源快照 | 历史问答、候选题、已发布测验的原文副本 | 原资料删除先标失效且不映射到新切片；隐私删除请求和到期清理也覆盖这些副本 |
| 私有执行记录 | 请求响应、步骤及工具结果 | 先移除凭据；与会话相同的归属/留存/删除约束 |
| 缓存 | 若后续引入的内容、检索与权限缓存 | 初版未实现；引入时必须列键范围、失效策略和TTL，不能假定不存在副本 |
| 备份/恢复介质 | 数据库、向量和文件备份 | OPS-10 的14天轮转；活跃备份能定向清理则清理，否则隔离至到期销毁，并维护删除清单 |

写入：业务库建立处理记录→事务外存文件→切片与向量→完成标记；失败记录阶段、错误类型与下次重试，由处理器补偿，未就绪内容不进入检索。外部动作不夹在数据库事务中。

删除：业务库先撤销访问并记删除任务→清缓存/向量/文件→处理快照/执行记录→检查备份策略→完成确认。任务失败可以重跑，每个动作幂等，超重试上限进入人工处理；具体重试参数在实现前登记，不能静默丢弃。

备份中的删除最迟随14天轮转收敛，隔离期间不能供查询或测试。恢复必须在接流量前重放截至恢复时的删除清单和到期清理，防止数据复活；丢失删除清单阻断恢复上线。正常资料版本删除与隐私删除分别按功能规约处理，不能借历史快照规避删除请求。

## 检查清单与违规处理

本次执行：规则、分级、留存、副本及补偿明确。实现后执行：建立一条测试资料及历史引用，在写入/删除中途注入失败，重跑至各副本收敛；恢复备份后确认已删除内容不重新可见。

结构未同步字典先补字典；归属/唯一约束失效补数据约束及回归。遗漏副本补入清单、完成清理和演练后再放行；不以清空环境作为升级方案。
