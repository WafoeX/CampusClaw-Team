## MODIFIED Requirements

### Requirement: IX-01 可定位切片与有界发布

系统 SHALL 支持自动、教师自定义窗口和 Markdown 标题切片，以原文版本、索引版本、切片 ID 和零基码点半开区间定位。只有本班教师可触发或查看构建。创建构建 SHALL 以 202/0 返回 build_id 和 task_id，构建、任务及发件箱同事务，worker 使用有界索引服务；查询只读，待处理和失败版本不进入任何检索。仅当整批关系索引与向量已确认一致，且资料、目标版本与发起者授权仍有效，才发布新版本；重建失败保留同原文版本的旧发布索引。操作 SHALL 有时限、容量和重试上限并提供授权诊断。 原文检索容量 SHALL 为 32,000 Unicode 码点（沿用预览解码），超出时在建立构建记录前返回 400/1000 并提示拆分。默认自动模式在段落策略超过 64 片时回退到固定 600 码点窗口和 80 码点重叠，覆盖全部非空正文。标题/自定义模式超过 64 片时提示改用自动模式，无截断发布。任务键包括资料 ID、原文版本、索引配置版本和构建 ID；陈旧执行不得推进发布指针。资料删除撤销发布与在途构建，失败补偿须可重跑。

#### Scenario: IX-N01 三种切片及版本一致性
- **GIVEN** A 班有 TXT 和含标题、前言、围栏代码的 Markdown，原文含 BOM、CRLF、中文和补充平面字符
- **WHEN** 教师依次提交自动、自定义窗口和标题构建，每次轮询到发布后由学生检索并核对原文
- **THEN** 受理 202/0 且只返回构建与任务标识等安全状态，标题不误识别代码中的伪标题，非空切片逐字等于所报区间；同版本每个点的 ID 和版本与切片一致，重建后只有新版本可检索，原文下载字节始终不变

#### Scenario: IX-B01 待处理可见性和边界
- **GIVEN** 一份资料从未构建，另一份已发布，按拟定上限配置两份均恰好产出 64 片
- **WHEN** 暂停在向量确认前，师生并发浏览与检索，教师查看状态，再放行发布
- **THEN** 原文均可读；首次无切片结果，重建只见旧索引，教师可见 pending/building；发布后才看到新版本且不混用旧片

#### Scenario: IX-B02 原文容量边界与自动回退
- **GIVEN** 两份原文分别有 32,000 与 32,001 码点，段落策略为前者生成超过 64 片
- **WHEN** 教师分别以自动模式创建首次构建
- **THEN** 前者回退固定窗口，依赖正常时完整发布且不超过 64 片；后者提示按章节拆分，返回 400/1000，无构建、嵌入或向量副作用；两份仍可下载原文

#### Scenario: IX-F01 非法切片配置与容量
- **GIVEN** 本班教师持有 TXT 和可产出 65 片的资料
- **WHEN** 对 TXT 请求标题切片、提交重叠超过允许范围、再提交产生 65 片的构建
- **THEN** 前两项同步 400/1000 无任务；执行才可发现的容量超限为 202 后终态失败/1000；均不发布新版本，无部分切片可检索，原文仍可读；对片数超限给出切换自动模式的提示

#### Scenario: IX-F02 无索引管理权限
- **GIVEN** 学生知道本班资料和构建 ID
- **WHEN** 发起重建和查询状态，再匿名重放
- **THEN** 分别 403/1200 和 401/1100，不返回构建细节且无写入或外部调用

#### Scenario: IX-F03 索引资源不存在
- **GIVEN** A 班教师持有 B 班资料/构建 ID 以及格式合法的缺失 ID
- **WHEN** 对这些资料触发构建并查询指定构建
- **THEN** 均 404/1300，公开文案与 data 同构，无构建、嵌入或向量副作用

#### Scenario: IX-F04 部分写入与超时
- **GIVEN** 本班一份首次构建资料与一份有已发布旧版的资料
- **WHEN** 分别在写入一批点后注入失败或超时，再解除故障并以新键重试
- **THEN** 受理 202，教师可查询退避或终态故障 1500 及安全阶段，首次无索引、重建仍是旧版、原文均可读；显式重试完整发布新构建版本，终结失败版本不被复用，其残留经精确清理收敛

#### Scenario: IX-F05 幂等、租约与迟到发布
- **GIVEN** 同一构建正在运行且班级并发额已满
- **WHEN** 同键同内容重放、同键异内容重放、提交另一资料构建，再模拟进程中断和失效租约后的迟到发布
- **THEN** 同键重放返回原 202 和原构建/任务标识；异内容 409/1400，另一构建 429/1600；过期构建可诊断并可重试，旧执行即使写入点也不能推进发布指针，残留进入补偿

#### Scenario: IX-F06 删除或撤权与迟到索引
- **GIVEN** 教师受理重建，worker 已开始写入向量但尚未发布
- **WHEN** 删除资料、推进原文或索引配置版本，或撤销发起教师权限，再放行旧 worker
- **THEN** 旧任务取消或被替代，不能发布或复活资料；检索不混入旧/失效版本，下载和出处服从现有授权，精确补偿重跑后无孤儿点或构建副本
