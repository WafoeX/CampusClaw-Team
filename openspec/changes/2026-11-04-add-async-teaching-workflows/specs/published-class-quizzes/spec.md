## Purpose

让本班教师依据已审核题目发布章节测验，并为学生提供稳定的题目与资格契约，使答案在开放时间之前受到独立保护。

## ADDED Requirements

### Requirement: QZ-01 不可变测验与答案门控

系统 SHALL 只允许本班教师以当前已审核的题目修订发布测验，冻结题目、分值、评分依据、出处引用、发布时间、截止、开放时间与参与名单。学生 SHALL 按当前身份和冻结名单读授权投影，开放前不得通过页面、API、下载、任务、出处、会话或工具获得受保护答案及可推断信息。

#### Scenario: QZ-N01 审核后发布并冻结
- **GIVEN** 本班教师有已审核题及合格学生名单
- **WHEN** 发布后编辑题库并新增本班学生，再读取测验和评分依据
- **THEN** 发布快照、名单和时点不变，后来入班者未获得既有测验资格

#### Scenario: QZ-B01 开放时刻与学生投影
- **GIVEN** 学生已有成功评分，开放时间设在截止之后
- **WHEN** 在开放前一时刻、恰到开放和开放后分别读取本人结果
- **THEN** 开放前只有粗粒度状态及本人作答；到开放才可见总分、逐题正误、解析及授权出处

#### Scenario: QZ-F01 非法配置或未审核题
- **GIVEN** 教师正在编辑本班草稿
- **WHEN** 提交空题、无参与名单、超范围分值、早于截止开放或未审题
- **THEN** 参数错误 400/1000，状态冲突 409/1400，均无发布快照

#### Scenario: QZ-F02 学生直接发布
- **GIVEN** 本班学生知道发布 API
- **WHEN** 以学生身份调用
- **THEN** 403/1200，无测验状态、名单或审计成功变化

#### Scenario: QZ-F03 跨班和缺失资源
- **GIVEN** A 班教师、学生知道 B 班测验与题目 ID
- **WHEN** 教师越界组卷或发布，学生越界直读，并用缺失 ID 对照
- **THEN** 404/1300 同构，无试题、身份、答案或写入

#### Scenario: QZ-F04 发布事务失败
- **GIVEN** 题目与名单本可发布
- **WHEN** 在写入快照或名单时注入数据库故障
- **THEN** 503/1500，测验仍未发布，快照与名单无半提交

#### Scenario: QZ-F05 提前访问及泄露旁路
- **GIVEN** 测验已评分但未开放，测试答案含受保护标记
- **WHEN** 用学生身份尝试直接读结果及出处、访问下载、并经普通会话或 MCP 请求同一答案数据
- **THEN** 响应、帧、模型输入和工具参数无受保护数据、总分及逐题线索，不可借任务错误反推
