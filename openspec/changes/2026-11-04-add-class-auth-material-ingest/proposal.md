# 第 3 课认证、班级隔离与资料入库

## Why

教师需要集中管理本班教学资料，师生需要从同一入口核对原文。与群聊转发及依靠链接保密相比，班级资料库可以按当前身份逐次授权，撤销登录后立即阻断后续访问，并用可复现的 A/B 班实验验证隔离。

## What Changes

- 建立单班级账号、教师与学生角色、可吊销登录会话，以及合成 A/B 班种子。浏览器使用短期、可撤销的 Cookie 登录会话，刷新保留有效会话，注销与再次登录使旧会话失效。
- 教师上传、改标题、调整展示顺序和删除本班资料。师生可按班级隔离列出、预览和下载原文。支持直接输入文字以及 UTF-8 TXT、Markdown。
- 元数据和正文同事务写入，使用稳定资料标识和原文版本，为第 4 课切片与出处留接口。章节与归类、切片、索引、检索及索引副本删除规约由第 4 课接续。Swagger、SSE 接入安排在后续变更。
- 登录页沿用示例的深红品牌区和浅色双栏。资料页和教师工作台使用白色侧栏、班级顶栏及浅灰背景上的白色卡片。正式登录使用账号和口令，界面按当前身份显示本变更已交付的入口。
- 课内验收以三项可观察结果为准：匿名资料请求无任何内容；跨班详情和下载与不存在同构；学生上传返回功能拒绝，两张资料表和文件目录均无写入。补测伪造身份、口令和令牌失败、非法输入、数据库故障及正文写入失败。
- 按项目设计采用服务端 Cookie 会话，对写请求增加同源校验。放弃 JavaScript 持有 Bearer、客户端自包含权限及静态附件路径。首版区分 1 MiB 原文保存上限和 32,000 码点的检索容量，超检索容量时允许保留原文并提示按章节拆分。选用数据库保存原文字节，放弃独立原文件作为第二份在线副本。

## Capabilities

- `class-auth-material-ingest` — 从登录和班级授权到班内原文的写入、读取与清理，作为一份端到端增量规格。

无已归档主规格变更。

- 本课业务装配在骨架通用授权机制上新增显式登记的登录例外，保留骨架装配的探针规则。实施前对照上游骨架规格，若主规格将探针限制写成全应用永久限制，先评审对应完整条款的增量并严格校验。
