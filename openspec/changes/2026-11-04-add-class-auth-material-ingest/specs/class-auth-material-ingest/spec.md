## Purpose

为每个班级建立可撤销的师生身份与独立的原文资料空间，让教师能组织教学资料、师生能核对原文，并能通过请求结果和存储副作用复现访问隔离与写入原子性。

## ADDED Requirements

### Requirement: CA-01 登录、换发与撤销

系统 SHALL 使用当前数据库账号与口令哈希认证，向有效账号签发有期限且可立即撤销的 Bearer 令牌。每个账号同一时刻至多一个有效登录会话。成功换发原子撤销此前会话，注销成功后原令牌立即失效；停用或重置口令时撤销会话。浏览器只在当前页面内存持有令牌，口令只经登录请求体传输，令牌只在登录成功响应中签发，后续通过 Authorization 请求头提交。未知账号、错误口令和停用账号使用同一失败结果。

#### Scenario: AUTH-N01 合成班级登录与换发
- **GIVEN** A/B 班各有一名启用的合成教师和学生
- **WHEN** 四人登录，随后 A 班教师再次成功登录
- **THEN** 登录为 200/0 并签发有期限的新令牌；A 班教师旧令牌访问受保护接口为 401/1100，其他三人的会话仍有效

#### Scenario: AUTH-N02 注销和口令重置
- **GIVEN** 三个账号各有一个有效令牌
- **WHEN** 一个账号注销，在隔离数据管理流程中重置第二个账号口令并停用第三个账号，再重放各自的旧令牌
- **THEN** 注销为 200/0，旧令牌均返回 401/1100，原会话均已撤销；重复注销无额外写入

#### Scenario: AUTH-B01 到期边界与浏览器持有
- **GIVEN** 账号已登录，测试可控制时钟和浏览器页面
- **WHEN** 在到期前一瞬、恰好到期时分别请求，并检查地址、浏览器存储和刷新后的新页面
- **THEN** 到期前令牌可用，到期时为 401/1100；地址与浏览器持久存储无原令牌，刷新后需重新登录

#### Scenario: AUTH-F01 登录参数不合法
- **GIVEN** 没有登录请求在途
- **WHEN** 请求缺少口令、口令类型错误或附带 role/class_id
- **THEN** 返回 400/1000，未创建、换发或撤销任何会话

#### Scenario: AUTH-F02 凭据失败及账号枚举
- **GIVEN** 有启用账号和停用账号，另有未登记的登录名
- **WHEN** 对启用账号提交错误口令、对停用账号提交正确口令、对未登记名提交格式合法的口令
- **THEN** 三者同为 401/1101，公开文案和 data 一致，无令牌、Cookie 或会话写入，三条路径均经过口令哈希验证工作

#### Scenario: AUTH-F03 无效令牌与伪造头
- **GIVEN** 受保护资料入口已登记
- **WHEN** 分别提交缺失、畸形、未知、已过期、已撤销的令牌或仅提交伪造身份头
- **THEN** 均为 401/1100，未访问资料业务处理器，无原文及写入

#### Scenario: AUTH-F04 认证依赖故障与换发回退
- **GIVEN** 启用账号已有有效会话
- **WHEN** 注入账号查询故障，再单独注入换发事务在提交前的写入故障
- **THEN** 均为 503/1500 且无新令牌；恢复依赖后确认失败事务未撤销原会话、未写入新会话

### Requirement: CA-02 当前班级与功能权限

系统 SHALL 按路由及方法显式登记策略，缺少策略默认拒绝。受保护请求逐次从当前数据库身份确定角色、班级和账号状态。资料列表和总数只来自本班，按 ID 的读写也需校验当前归属。允许本班师生读取，只有本班教师可写入。应用生成的业务 JSON 使用 code、message、data、request_id，并返回 X-Request-ID；访问拒绝时 data 为 null。资料内容只能经授权 API 返回。

#### Scenario: ACL-N01 A/B 班读取与组织
- **GIVEN** 两班各有师生且各有本班资料
- **WHEN** 四人列出、预览本班资料，A 班教师改本班一条资料标题和顺序
- **THEN** 读取均为 200/0，列表和总数只含本班；修改仅作用于指定本班资料，资料 ID、原文字节和原文版本不变

#### Scenario: ACL-B01 班内空列表及稳定分页
- **GIVEN** B 班无资料，A 班有多条顺序值相同的资料
- **WHEN** B 班学生列出资料，A 班学生按页浏览未变动的数据
- **THEN** B 班为 200/0、空列表及总数 0；A 班无重复、遗漏或跨班行

#### Scenario: ACL-F01 匿名内容隔离
- **GIVEN** 两班有资料，已知其资料 ID 和显示文件名
- **WHEN** 匿名请求列表、详情、下载及猜测的静态文件路径
- **THEN** 资料 API 为 401/1100，猜测路径不可读；均无标题、总数、正文或附件字节

#### Scenario: ACL-F02 学生上传和管理被拒
- **GIVEN** A 班学生令牌有效，记录两张资料表的行及测试文件目录基线
- **WHEN** 提交合法的文字上传和文件上传，再尝试组织或删除本班资料
- **THEN** 均为 403/1200；两张表的内容及目录快照均无变化，上传存储动作未调用

#### Scenario: ACL-F03 跨班与不存在同构
- **GIVEN** A 班教师和学生均已登录，已知 B 班资料 ID，另有格式合法且未分配的 ID
- **WHEN** 两种身份分别请求两种 ID 的详情和下载，A 班教师还分别尝试组织和删除
- **THEN** 每对结果均为 404/1300，公开文案与 data 一致且无附件头；只排除请求标识等动态值，无数据库或目录副作用

#### Scenario: ACL-F04 客户端伪造身份
- **GIVEN** A 班师生各有有效令牌
- **WHEN** A 班学生带伪造教师身份头上传，A 班教师在合法写入或列表参数附加 class_id 或 role
- **THEN** 学生仍为 403/1200，教师请求为 400/1000，身份和任何资料归属均无变化

#### Scenario: ACL-F05 当前身份变化与依赖故障
- **GIVEN** A 班教师持有效令牌
- **WHEN** 在测试库将其降权后重放写请求，再使身份查询不可用并请求读取
- **THEN** 写为 403/1200，读为 503/1500，未沿用旧权限，均无内容及资料写入

### Requirement: CA-03 有界原文入库

系统 SHALL 接受单份直接输入的文字或单个 UTF-8 TXT/Markdown 文件，资料原文最大 1 MiB。拒绝空白正文、无效 UTF-8、NUL、非允许扩展名或声明类型、路径型文件名及混用输入来源。元数据与原文字节必须同事务提交，资料 ID 稳定且新原文版本为 1。原文放在私有数据库，应用不独立落盘。新建请求按授权主体、班级和幂等键约束副作用。

#### Scenario: ING-N01 两种入口原文保真
- **GIVEN** A 班教师登录，持合法幂等键和标题
- **WHEN** 分别提交文字和含 BOM 或 CRLF 的合法 TXT/Markdown 文件
- **THEN** 各返回 201/0，各有一条本班元数据和一条正文，资料 ID 不重复、原文版本为 1；原文字节保持一致，目录无应用写入

#### Scenario: ING-B01 字节边界及重放
- **GIVEN** 教师有恰好 1 MiB 的合法 UTF-8 正文和一组幂等键
- **WHEN** 以同键同内容重放并发请求，再单独提交超出一字节的正文
- **THEN** 合法请求只产生一对资料行并返回同一资料标识；超限返回 400/1000，无新增行及文件

#### Scenario: ING-F01 非法文件与路径
- **GIVEN** 本班教师已登录且记录数据库与目录基线
- **WHEN** 分别提交非法扩展名、伪造媒体类型、畸形 UTF-8、NUL、空白内容、目录穿越文件名、绝对路径文件名或文字和文件混用
- **THEN** 各返回 400/1000，无两张表、幂等记录或目录写入，无路径回显

#### Scenario: ING-F02 正文写入失败
- **GIVEN** 本班教师提交合法文件，注入元数据已写入当前事务、正文写入时的数据库故障
- **WHEN** 请求失败后用独立连接与目录快照核验，再解除故障用同键重试
- **THEN** 首次为 503/1500，元数据、正文、成功幂等记录和应用文件均无残留；重试为 201/0 且只创建一对行

#### Scenario: ING-F03 资料库不可用
- **GIVEN** 有效教师身份已解析，资料持久层不可用
- **WHEN** 提交合法上传请求
- **THEN** 返回 503/1500，无成功标识或文件；恢复后无失败请求遗留资料

#### Scenario: ING-F04 幂等键冲突和已删除资料重放
- **GIVEN** 教师已有一次成功上传
- **WHEN** 在键有效期内用原键提交不同内容；再删除原资料并重放原请求
- **THEN** 两次重放均为 409/1400，均无新增行或资料复活

### Requirement: CA-04 授权下载与清理

系统 SHALL 以资料 ID 定位原文，每次下载在返回任何附件头或字节前完成授权；附件按原字节、服务端安全命名返回。预览把文字和 Markdown 当不可信纯文本显示。教师删除在一个事务内撤销访问并清理正文及元数据，同步成功后不再可读。删除后的备份按数据与运维规范隔离轮转，恢复前补做删除核对。

#### Scenario: IO-N01 合法预览、下载和删除
- **GIVEN** A 班有两份不同来源的资料，教师和学生均已登录
- **WHEN** 学生预览及下载两份资料，教师随后删除其中一份
- **THEN** 预览为 200/0，下载为 200 且附件字节与入库原文一致；删除为 200/0，被删资料的两张表均无对应行，列表、详情和下载均不再提供该资料，另一份仍可读

#### Scenario: IO-B01 预览的脚本与危险链接
- **GIVEN** 本班资料含脚本标签和危险链接文本
- **WHEN** 师生预览并下载
- **THEN** 页面展示文字且不执行脚本或生成危险链接，下载字节与原文相同

#### Scenario: IO-F01 不存在与重复删除
- **GIVEN** 一份资料已成功删除，另一份资料仍存在
- **WHEN** 重复删除前者，再用其 ID 请求下载
- **THEN** 均为 404/1300，无附件头或新副作用，仍存在的资料不受影响

#### Scenario: IO-F02 删除事务中断
- **GIVEN** 教师可删除本班资料，已注入删除一张表后提交前的数据库故障
- **WHEN** 发起删除、解除故障后读取并重试删除
- **THEN** 首次为 503/1500 且恢复后两行与下载原文完整；重试为 200/0 且两行共同消失，目录始终无变化

#### Scenario: IO-F03 下载依赖故障
- **GIVEN** 本班学生身份有效，资料库在获取原文时故障
- **WHEN** 请求下载
- **THEN** 返回 503/1500 JSON，无附件头或部分原文字节

#### Scenario: IO-F04 非法标识及越权写入
- **GIVEN** 本班有资料且分别持有教师、学生令牌
- **WHEN** 教师下载非法格式 ID，学生尝试删除本班资料
- **THEN** 分别为 400/1000 和 403/1200，均无附件及数据库或文件副作用
