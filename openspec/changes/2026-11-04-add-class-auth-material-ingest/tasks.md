- [x] 1.2 采用 `project-data-change` 技能，锁定 SQLAlchemy 及迁移工具版本，在适配器中接入仓储，建立班级、账号和登录会话迁移，先补相应字典、留存期限及恢复说明；在隔离 MySQL 验证干净库、骨架库升级、重跑与隔离回退。种入合成 A/B 班各一师一生，重跑确认无重复且不覆盖口令和角色。

## 2. 授权

## 3. 入库

输入为教师写权限、班级作用域及数据规范。输出为私有的资料元数据与原文、上传接口和组织持久化。
