# 第 3 课实施任务与证据计划

以下是后续实施任务。每次交付一组，通过该组场景与适用门禁并留证后再勾选。实施人负责代码与取证，运维负责隔离环境及迁移恢复，另一成员负责人工复核，课程联络人确认课件口径。实名由小组指定。能力和场景以 [增量规格](specs/class-auth-material-ingest/spec.md) 为准，参数与副本取舍见 [设计](design.md)。

## 1. 认证

输入为已验证可运行的开发骨架及隔离 MySQL。输出为班级、账号、可撤销会话、合成种子与登录入口。

- [ ] 1.1 核对第 7 课启动与门禁证据，核对 AC-01 精确公开路由装配及 AC-N03 回归。登录页内嵌启动资源；仅登记登录页 GET/HEAD 与登录 API POST。分别验收页面直访跳转和 API 401。课程联络人记录 Cookie/Bearer 四项语义、三项课件验收和实际接受结论。运行本变更 OpenSpec 严格校验并检查主干保护证据，再进入编码。
- [ ] 1.2 采用 `project-data-change` 技能，锁定 SQLAlchemy 及迁移工具版本，在适配器中接入仓储，建立班级、账号和登录会话迁移，先补相应字典、留存期限及恢复说明；在隔离 MySQL 验证干净库、骨架库升级、重跑与隔离回退。种入合成 A/B 班各一师一生，重跑确认无重复且不覆盖口令和角色。
- [ ] 1.3 接入登录、当前会话、换发、注销、到期和停用/重置口令撤销，完成内存持有的登录视图。用隔离 pytest 验证 AUTH-N01/N02、AUTH-B01、AUTH-F01–F04，另并发换发与迟到注销，验证只有当前令牌有效且旧注销不误撤销新令牌。

## 2. 授权

输入为当前身份解析、A/B 夹具和骨架通用策略。输出为按方法登记的班级资料策略与只读/组织入口契约。

- [ ] 2.1 以测试夹具先接入按方法的资料权限和当前身份，验证默认拒绝、未知路径 404、未支持方法 405，以及匿名、降权、伪造字段、数据库故障均无处理器或存储副作用。执行骨架授权回归，覆盖 ACL-F01/F02/F04/F05。
- [ ] 2.2 在服务与仓储边界建立班级内列表、详情及组织校验；用隔离夹具验证 ACL-N01、ACL-B01、ACL-F03 的列表/详情/组织分支和 ACL-F04。并发组织以修订号防止静默覆盖。后续持久化与下载接入后对真实入口重跑全套 ACL 场景，夹具结果只作本组证据。

## 3. 入库

输入为教师写权限、班级作用域及数据规范。输出为私有的资料元数据与原文、上传接口和组织持久化。

- [ ] 3.1 按 `project-data-change` 技能新增资料、正文和幂等表结构及字典，验证一对一、班级索引、外键和幂等唯一约束。实现有界内存上传、文件和文字白名单，验证 1 MiB 字节边界、32,000/32,001 码点的检索容量提示、编码、类型、文件名与请求体限制。执行 ING-N01、ING-B01、ING-F01 与 ACL-F02 的真实上传断言。
- [ ] 3.2 实现资料和正文及成功幂等记录的同事务创建，补提交未知后的同键核对及组织版本检查。执行 ING-F02/F03/F04 的入库分支和真实 MySQL 并发重放。在元数据 SQL 已执行后注入正文写入失败，从独立连接确认两张资料表和成功幂等记录无变化，核对目录快照，再同键重试。删除后重放在第 4 组复验。

## 4. 下载与清理

输入为已授权原文与元数据、删除凭证和测试基线。输出为预览、下载、删除和可验证的留存恢复。

- [ ] 4.1 完成资料列表、详情与教师工作台的内存会话视图，接入按资料 ID 授权下载。执行 IO-N01 的预览/下载分支、IO-B01、IO-F03/F04 与 ACL-F01/F03 的下载分支。核对内容处置头、原文字节、四态、请求标识与浏览器下载全过程。
- [ ] 4.2 同事务删除资料和正文、标记幂等结果并保留去内容删除凭证。验证 IO-N01 的删除分支、IO-F01/F02、ING-F04 的删除后重放以及 ACL-F02/F03 的删除分支。运维在隔离 MySQL 演练故障、同 ID 重试、备份恢复后重放删除凭证、回退到骨架应用制品，并记录耗时和清理结果。
- [ ] 4.3 采用 `project-add-tests` 和 `project-review` 技能，按正常、失败、边界组织完整回归。复核静态门禁选择当前变更（当前骨架 Makefile 支持 `make check CHANGE=2026-11-04-add-class-auth-material-ingest`），执行真实门禁、应用 pytest、隔离 Compose 冷启动与真实 MySQL 集成、浏览器走查，保留实际命令与退出码。同步 README、页面清单、API 契约及数据字典，归档真实证据并提交人工复核。
