## Context

仓库已有 Flask、Compose、默认拒绝授权、MySQL/Qdrant 探测及统一门禁。第 5 课规约提供[受控技能](../2026-11-04-add-streaming-ai-assistant/specs/bounded-ai-skills/spec.md)和[私人流式会话](../2026-11-04-add-streaming-ai-assistant/specs/private-streaming-sessions/spec.md)，其实现与上游业务验收待完成。第 6 课在宿主服务层扩展可选能力，保留原单次问答、来源检查、流式终态和执行记录归属。

## Goals / Non-Goals

- Goals — 用真实协议调用自建服务；把发现、审阅、启用、执行和断开串成可复验链路；对失败、跨班、断开和不可信结果提供明确判据。
- Non-Goals — 不提供公网 MCP 服务、第三方用户授权流程、通用代理、写工具、任务队列、上传脚本、后台自动执行或测验数据访问。

## Decisions

### 1. 固定协议与只读教学工具

- `mcp-server/` 作为同仓独立 Compose 服务，与宿主同网络，通过服务名访问。仅 `/health` 对内网免认证，返回最小就绪状态。工具服务端口不发布到宿主机，进程不持有 MySQL、Qdrant 或模型凭据，两个工具纯计算。宿主与工具服务分别从私有环境取同一服务令牌，缺失时自建服务启动失败，错误令牌拒绝。主应用就绪不依赖这一可选服务；Compose 与应用探测均避免工具故障牵连主链路。
- 固定 JSON-RPC 2.0、MCP Streamable HTTP `2025-06-18`。宿主先发 `initialize`，核对协议版本和 tools 能力，发 `notifications/initialized`（HTTP 202 空响应），后续请求携带 `MCP-Protocol-Version`、若协商了会话则携带 `Mcp-Session-Id`。本地服务发放有界、短期、随机会话标识并绑定服务认证，重启或过期后旧标识失效；已认证请求访问过期/不存在会话返回 404，宿主在下一次显式连接时重新握手，不透明地重放本轮调用。
- 同一路径 `/mcp` 处理 POST 及 GET；本自建服务采用 POST JSON 响应，不提供独立 GET 流，返回 405。宿主 POST `Accept` 同时接受 JSON 和 SSE，并能有界读取 POST SSE 的匹配 JSON-RPC 响应。服务支持带有效会话的 DELETE 终止；断开先在业务层撤销，协议关闭为有界尽力操作。限制请求方法、Content-Type、单条报文及体积；验证 Origin，缺失仅允许有正确服务认证的服务器间调用。解析错误、无效报文、未知方法和非法参数分别使用 JSON-RPC `-32700/-32600/-32601/-32602`，不反射原始输入。工具业务执行失败用 `isError`，依赖不可用或认证失败单独分类。
- 采用官方版本约定并独立验证本服务和宿主，而非只让本项目两端互测。固定独立 MCP 客户端版本验证自建服务，并用支持 POST SSE 的协议夹具验证宿主。互操作核对握手顺序、协议版本、Origin、会话、请求 ID、错误及能力。服务令牌是受控 Compose 部署的机器凭据，未宣称提供面向第三方的 MCP 授权服务。[传输](https://modelcontextprotocol.io/specification/2025-06-18/basic/transports) · [生命周期](https://modelcontextprotocol.io/specification/2025-06-18/basic/lifecycle) · [工具](https://modelcontextprotocol.io/specification/2025-06-18/server/tools)

两项工具都公布名称、说明和 JSON Schema。输入顶层为对象，列出的属性全部必填，`additionalProperties: false`。禁止自由文本、表达式、URL、资源 ID 和额外字段。宿主与服务端均校验；响应为规范化教学数据的文本块，工具不写业务数据。

| 名称 | 适用范围 | 输入 schema 与结果 |
| --- | --- | --- |
| `formula_hint` | 线性方程、分数比较、三角形面积；提示下一步 | `topic` 为枚举 `linear_equation`、`fraction_comparison`、`triangle_area`；`stage` 为 `start` 或 `check`。返回经审核的步骤提示及稳定提示编号，不接收具体题目和作答，不给最终答案 |
| `unit_convert` | 非测验的普通单位练习，长度或质量同量纲换算 | `value` 为有限数值，范围 ±1000000、最多 6 位小数；`from_unit` 与 `to_unit` 均为 `mm/cm/m/km/g/kg` 枚举，跨量纲作为业务参数错误。使用十进制定值，返回数值、单位及换算因子；宿主仅在本轮有经验证的普通练习上下文时声明此工具，解题助手模式不声明 |

### 2. 登记、发现和安全出站

- 运维在私有部署配置登记连接键、固定协议、目标主机/端口/路径、准入网络、密钥引用及每个工具获批的参数和结果策略。教师从允许列表登记本班别名与连接键，只能选批准的地址。可展示安全的服务别名、连接状态与 `credential_configured` 布尔值。凭据和环境键名、内部诊断地址、解析 IP 不进教师视图。数据库存连接键及其版本，不存密钥原值。
- 连接以当前代次暂存 `connecting`，握手和有界全量发现均成功才在短事务内整体替换清单并标记已连接；任一步失败转 `disconnected`，原清单失去可用性。分页发现限制总页数、条数和字节，游标循环或重复工具名失败。清单以连接稳定 ID 和工具名唯一。新工具、说明或 schema 指纹变化默认待审且停用，审批记录含完整描述/schema、指纹、教师和时间；部署策略未允许的工具即使教师审批也不可启用。模型只收到审核通过且按部署策略规范化的声明，不直接复制服务端 instructions 或未审描述。
- 断开原子推进代次、清空有效清单并撤销可用引用；断开前已有发送许可的调用视为在途，尽力取消，返回后重验代次与权限，过期结果不回填。握手、发现、发送许可或审批若跨代次，旧结果不得恢复连接。服务别名登记后固定；删除用软删使老调用仍可归属，新资源沿用稳定 ID，不复用旧引用。
- 出站检查对登记解析、握手、发现和每次调用一致。规范化协议、地址、端口和路径，拒绝用户信息、任意 URL、重定向与非预期代理。检查全部 DNS 解析候选及 IPv4/IPv6 映射地址，连接固定到经校验 IP，保留批准的 Host/SNI，核对对端地址以防二次解析。外部服务用 HTTPS 和默认公信校验，拒绝内网、环回、链路本地、云元数据及保留地址。仅为部署声明的自建 Compose 服务名、端口和实际 Compose 网络配置明确私网例外；任意发现地址和模型参数不能触发例外。记录安全错误类别，不把地址诊断回传给模型。
- HTTP 适配使用同样的部署目录和策略。每个 HTTP 工具固定路由和方法、声明与字段白名单，使用经批准的只读 GET，参数做规范编码，配置清单代替远程发现且同样要审阅。端到端测试使用有确定响应的只读夹具。MCP 的 POST 是协议封装，自建工具仍为只读。仅允许 schema 和部署策略明确批准的标量出站，拒绝对话历史、原文、答案、密钥、链接和任意自由文本；不自动追踪工具返回的链接。

### 3. 管理接口和会话编排

| 接口与入口 | 契约 |
| --- | --- |
| `/console/connectors`，`GET /api/v1/tool-connector-options`，`GET/POST /api/v1/tool-connectors`，`GET/DELETE /api/v1/tool-connectors/{id}` | 本班教师选择部署批准项登记，查看范围内状态或移除；只读列表带稳定分页 |
| `POST /api/v1/tool-connectors/{id}/connections`，`DELETE /api/v1/tool-connectors/{id}/connections/current` | 建连接或显式重连；断开清空有效发现结果，重放断开无新副作用 |
| `GET /api/v1/tool-connectors/{id}/tools`，`PATCH /api/v1/tool-connectors/{id}/tools/{name}` | 只显示本班当前代次工具；以期望指纹审核和启停，过期版本 409/1400 |
| `GET /api/v1/tool-call-audit`，第 5 课本人 `GET /api/v1/runs/{id}` | 教师取本班去内容元数据；仅执行者可在本人记录看授权的合规工具数据 |
| 第 5 课技能保存接口 | `tools` 仍接受已有空数组或 `knowledge_search`；另允许不重复的 `tool@server` 受控引用。工具名 `[a-z][a-z0-9_]{0,63}`，服务器别名 `[a-z][a-z0-9-]{0,62}`；写入检查本班、连接、当前发现、审阅及启用 |
| `POST /api/v1/sessions/{id}/unit-practice` | 本人可为资料问答会话取得服务端生成的普通单位练习。用同一轮的幂等键绑定题面及参数，签发短期上下文。 |
| `POST /api/v1/sessions/{id}/messages` | 可选 `selected_tools`，缺省或空列表均不启用外部工具。新字段加入规范化幂等指纹，旧客户端省略时兼容。学生只能从本班启用的安全工具摘要选择 |

普通单位练习参数由宿主生成。短期上下文用部署密钥签名，绑定当前班级、本人、会话、题面和消息幂等键。浏览器拿到题面和签名票据，可原样发起本轮，不能替换题面或参数。签名票据不持久化，幂等指纹使用规范化练习值与签发时限。首次受理验证有效期，同键成功回放继续遵循原权限与留存。只有提议参数和已验证练习参数完全一致时，宿主才可执行 `unit_convert`。普通提问不因文字内容、客户端用途声明或模型分类获得换算权限。练习参数、工具结果与合法出处分开，保留资料问答的无证据零对话调用和出处校验；解题引导继续使用受控槽位。

页面沿用第 5 课入口和加载、空、正常、错误四态，增加待审、已连接、已断开、不可用提示；旧技能保留对知识库工具的原契约。接口沿用当前数据库身份、同源 Cookie 会话及写入防护和默认拒绝。角色不具备管理权返回 403/1200，匿名 401/1100，跨班/缺失同构 404/1300，参数非法 400/1000，未连接或陈旧指纹 409/1400，依赖不可达 503/1500。列表默认 20、上限 100，按时间和 ID 稳定分页。技能保存引用跨班或不存在时统一 404，已知本班旧引用在断开后保存返回 409。不可归属的模型提议在会话中只报告通用被拒，不提供远端存在性。

- 第 5 课按确定性路由选定技能后，取其工具引用、本轮选择、当前班级和连接启用、用途/数据策略的交集；每轮按最新配置生成最小候选。仅模型提出调用，宿主再次校验当前身份、权限、参数 schema、连接代次、目标策略、预算以及敏感数据出口。授权与短事务的许可写入是断开的线性化边界；网络操作在事务外执行，发出前尽可能再次核对，返回后检查当前代次。解题助手继续用受控提示渲染。资料问答无证据时维持第 5 课固定回复及零对话调用，工具结果不能冒充资料出处。
- 暂定每轮最多 2 个工具规划轮次、3 个工具提议（含拒绝）、2 秒/次，工具阶段总计至多 8 秒且含在第 5 课整轮预算内。响应传输上限 16 KiB，可回填文本最多 1000 码点。先拒绝不支持类型、越界结构、危险链接和指令式内容，再按边界截断其余合规文本。结合允许字段/结构、已审定义和注入样本测试，不单靠关键词防注入。合规结果仅作为工具数据消息回填，无远端指令执行。超时、拒绝、无候选、坏结果、审计不可写或超预算时使用已有合法信息回答，且维持原出处/答案规则。外部调用无隐式自动重试。
- 工具阶段在正文前完成，复用唯一 `meta` 并新增可选 `tools` 状态摘要，报告成功、被拒或出错及可公开理由，然后才推校验过的 `delta`。旧客户端可忽略新字段，`done/error` 语义不变。工具降级与基础检索故障分别判定。请求格式错误走流前 400；格式合法但已选引用在本轮不可用时不送模型或远端，由宿主生成一次拒绝结果并显示，同班有归属的旧连接按原标识记审计，未知或越界只给通用状态。对话幂等重放只读已有状态，不能再次触发工具。

### 4. 审计与隐私

- MySQL 登记连接、代次、发现、审批、启停和只增调用结果，配置表持有同班复合外键。每个工具提议在应用内有稳定尝试号；以班级、运行尝试、轮次和序号唯一。先记可恢复的尝试凭据，网络后在短事务追加唯一结果；不更新结果行。不可归属的请求追加本班通用拒绝结果，不存模型任意原名；故障恢复对无法确认结果的尝试追加一条出错记录，不重发调用。审计存储不可用时不允许新外部执行，日志只记脱敏故障类别。
- 每条可归属调用记录包括当前操作者受控标识、内部会话/运行 ID、工具引用、调用轮次及序号、UTC 时间、结果、耗时、公开错误类别、配置指纹、请求标识。连接软删后保留去内容历史；更名采用新登记及重新审阅。原始参数、合规工具结果及模型上下文按第 5 课约束只在本人执行记录保留；原始恶意响应、令牌、未批准出站数据不保留。教师的本班工具运维视图只显示工具、时间、结果、耗时和错误类别等去内容元数据，不显示学生标识、会话 ID、输入、结果原文或私有跳转；运维只能按受控授权读取必要的脱敏日志和指标。课件“管理角色看自己范围”与“改名/删除后不记无归属记录”按此最小权限和稳定归属映射，提交课程确认。
- 运行日志基线 14 天，去内容审计 90 天，私人正文随学期结束后 30 天内清理，备份按 14 天轮转。登记清理触发、失败补偿、最小删除记录及恢复重放；此处只增指正常操作不可改写，依法或按数据规范执行的清理单独留去内容证据。
- Swagger 从同源契约生成，试调登记、连接、发现、审批、技能保存和会话接口。主应用权限与工具服务机器凭据用独立方案，Swagger 示例无真实令牌。按第 5 课 `apitest` 和真实 Compose 方案留失败、重试、跨角色、网络副作用及私有字段证据。

## Risks / Trade-offs

- 工具阶段增加首段延迟 → 记录连接、调用、首段耗时及 P95，超预算即降级；参数由实施与运维角色在实施前登记验证。
- 发现内容漂移及 DNS 重绑定 → 审批绑定指纹，执行重校代次、解析和对端，模拟替换与重定向验证。
- 管理操作与在途结果竞争 → 不持事务做网络操作，断开后拒绝新许可，已在途结果重校后才可使用。
- 课程演示与安全基线有差异 → 以部署选项代替任意 Base URL，以去内容运维视图及稳定归属映射课件，将同伴复现与课程确认交最终验收 2.10、1.5。

## Migration Plan

宿主接入前复核第 5 课可运行基线、规约和相关自动化回归。增量建立连接、清单、审批与审计表，旧技能引用兼容并默认不启用外部工具。独立验证新服务后启用班级配置，回退先停用外部能力及新写入口、收敛在途，再回到先前宿主制品，保留隔离数据及清理记录。迁移与备份恢复在真实 MySQL 隔离环境验证，恢复接流量前重放撤销与清理。

### 2026-11-05 验证职责与依赖修订

实现任务以自动化功能回归及可运行交接为退出条件，专项安全验证交安全预检/修复，人工测试统一交项目最终验收。本文涉及的同伴测试、人工评测和课程确认按该调度执行，不另作实现交付前置；基本业务权限与错误处理契约不变。合并前代码评审独立保留，不能把开发候选当作已批准主干。直接依赖与组内顺序以 tasks 的「推进依赖」为准，主规格归档顺序不阻断使用已验证的开发契约。
