## Why

教师希望为班级助手配置可靠的教学工具，学生希望在一轮对话中看清用了哪些工具及其结果状态。相比在模型提示词中直接交给模型外部访问能力，由宿主管理候选集和执行权限能限制数据外发，且工具故障时仍可使用已有检索和对话。

## What Changes

- 同一工程增加独立 Compose 服务，提供教学用 `formula_hint` 与 `unit_convert`。固定 MCP Streamable HTTP `2025-06-18` 互操作基线，支持初始化、发现、调用与独立健康检查。
- 教师从部署批准的服务目录登记本班连接、发现及审阅工具，按班启用并绑定至技能。学生可在本轮选择工具。会话内的数值换算仅用于服务端签发、绑定本人的普通单位练习。另提供走同一宿主安全策略的只读 HTTP 适配。
- 模型在最小候选集中提出调用，由宿主按当时的身份、班级、绑定、参数、出站规则及预算决定执行。调用状态在流式正文之前可见，工具故障优雅降级。
- 增加只增调用记录、本人详情和按角色授权的去内容运行视图，补 Swagger、真实 Compose 自动化验证，四项真人交叉验证交最终验收。

本课验收从部署自建服务开始，走连接、发现、审阅、绑定、会话调用和记录，再验证断开拒绝。放弃教师输入任意 URL、直接转发模型参数、默认开放所有发现工具及公开他人原文，以保护权限和对话数据。写工具、后台队列、浏览器直连 MCP 与第三方账号授权暂不纳入。

## Capabilities

### New Capabilities

- `mcp-teaching-service` — 自建教学服务及固定协议版本。
- `class-tool-connectors` — 本班连接、发现、审阅、启用、断开及安全出站。
- `guarded-tool-dialogue` — 技能引用、按次选择、受控调用与 SSE 降级。
- `tool-call-audit` — 只增记录、私人执行详情和脱敏运行视图。

### Modified Capabilities

第 5 课既有会话行为、事件类型及安全约束保持有效。本课增加可选的工具选择和 `meta` 工具状态，扩展技能的受控引用集合，已有合法技能文件继续兼容。
