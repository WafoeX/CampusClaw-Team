## Purpose

使教师只能在本班管理运维批准的服务，安全地发现并审核工具定义，通过原子更新和断开撤销让权限及工具版本随时可查。

## ADDED Requirements

### Requirement: CN-01 班内连接与可信发现

系统 SHALL 限定本班教师登记、连接、审阅、启停和断开部署白名单内的 MCP 或只读 HTTP 服务。连接成功以握手及全量发现成功为前提，失败则不可用。新工具和变动定义 SHALL 审阅后启用；断开撤销旧引用和清单。所有出站 SHALL 检查地址、解析、对端和数据策略，并禁止重定向。

#### Scenario: CN-N01 连接后审阅启用
- **GIVEN** 部署已批准一个 MCP 服务和一个只读 HTTP 连接项
- **WHEN** 教师登记本班连接、完成发现或载入 HTTP 配置并审阅启用获准工具
- **THEN** 状态和工具定义可核对，未审前不可启用；响应只暴露凭据配置标记，不返回令牌或引用键名

#### Scenario: CN-B01 重复发现与定义漂移
- **GIVEN** 已有两个审阅通过且启用的工具
- **WHEN** 重连未改变的服务，再重连只更改一项说明或 schema 的服务
- **THEN** 清单条数不翻倍，未改变的批准有效，变化项回到待审且不可调用，过期指纹不能批准新版本

#### Scenario: CN-B02 断开与迟到发现
- **GIVEN** A 班连接正在发现，远端结果尚未返回
- **WHEN** 另一请求断开，再释放旧发现响应
- **THEN** 清单保持为空，旧响应不恢复连接；合法的重复断开无新副作用

#### Scenario: CN-F01 未批准地址和输入
- **GIVEN** 教师可选已批准目录项
- **WHEN** 提交任意 URL、非法别名、含用户信息的地址或未允许的连接键
- **THEN** 400/1000，无 DNS、网络及持久化副作用

#### Scenario: CN-F02 学生操作管理接口
- **GIVEN** A 班学生已认证
- **WHEN** 直接登记、连接、启停或断开
- **THEN** 403/1200，无状态、清单、审批或网络变化

#### Scenario: CN-F03 跨班连接和缺失连接同构
- **GIVEN** A 班教师知道 B 班连接 ID
- **WHEN** 列出连接，并分别用 B 班及缺失 ID 查工具或断开
- **THEN** 列表无 B 班对象，两类直访均 404/1300 同构，无工具数据或状态变化

#### Scenario: CN-F04 握手或全量发现失败
- **GIVEN** 曾连接成功的服务有现成清单
- **WHEN** 分别注入错误凭据、第二页超时或游标循环后重新连接
- **THEN** 连接不可用，旧清单不再可执行，不发布部分清单；错误不回显凭据

#### Scenario: CN-F05 SSRF 与重绑定
- **GIVEN** 已批准的域名之前解析合法，出站可观测
- **WHEN** 改为返回私网、环回、IPv4 映射或链路本地地址，另测试合法对端返回重定向及连通对端与校验地址不符
- **THEN** 越界目标无业务请求、凭据或转发；连接失败不改变其他班级或主应用状态
