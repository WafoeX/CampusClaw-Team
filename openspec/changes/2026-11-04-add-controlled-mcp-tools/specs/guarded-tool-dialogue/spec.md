## Purpose

让师生在当前对话选择获准的教学工具，由宿主在真实调用前确认授权、参数及预算，并通过既有 SSE 协议展示调用状态及安全降级。

## ADDED Requirements

### Requirement: TD-01 按次授权与有界工具调用

系统 SHALL 校验技能保存时的 tool@server 引用及执行时的当前授权。模型候选 SHALL 受本班、当前连接、批准和启用、技能绑定、按次选择及用途共同限制；宿主验证 schema、预算和出站字段后才能执行。会话换算 SHALL 限定为服务端生成且验证为当前班级、本人、会话、题面和幂等键的普通单位练习，提议参数必须等于该练习参数。合规结果只作数据回填，工具状态在正文前可见；失败或超限降级而不改变原出处、隐私、解题或幂等契约。

#### Scenario: TD-N01 真正触发并先显示调用状态
- **GIVEN** 本班教师连接、审批、启用并在技能绑定 formula_hint，自建服务与宿主同网
- **WHEN** 学生选择该工具并发问，模型提出合法调用
- **THEN** 自建服务真实收到一次 tools/call，meta 先于第一条 delta 显示成功，受控提示采用合规工具数据，done 和私有回读符合第 5 课

#### Scenario: TD-B01 兼容与最小候选集
- **GIVEN** 有旧技能清单及当前多个可用工具
- **WHEN** 旧客户端省略 selected_tools，再以新客户端选定一个与技能绑定交集非空的工具，并对已完成请求同键重放
- **THEN** 旧请求兼容且无外部工具调用，新请求仅声明交集且按用途过滤，回放不会再发工具请求；资料问答无证据仍零对话调用

#### Scenario: TD-F01 非法引用、schema 和出站字段
- **GIVEN** 教师可保存技能，模型可提出工具请求
- **WHEN** 保存格式非法的引用，或模型传入额外字段、自由文本、资料原文、令牌或未批准值
- **THEN** 保存返回 400/1000；执行提议被拒且无远端发包，响应和日志无输入原值

#### Scenario: TD-F02 越权与断开
- **GIVEN** 已有指向本班曾启用工具的技能，另有未绑定工具
- **WHEN** 模型提议调用未绑定项，或教师断开后学生用原技能和已选工具继续发问
- **THEN** 工具状态为被拒且无新调用，断开后旧引用不能重新保存；会话按原权限降级继续并新增一次可归属拒绝记录

#### Scenario: TD-F03 未注册或跨班工具
- **GIVEN** A 班教师或学生知道 B 班工具引用
- **WHEN** 保存时尝试绑定该引用或不存在引用，再以模型伪造工具名尝试调用
- **THEN** 保存均 404/1300 同构；调用只公开通用被拒，无跨班信息、原样反射或远端执行

#### Scenario: TD-F04 外部依赖超时或坏响应
- **GIVEN** 当前问答已有合法证据且模型提出批准的工具
- **WHEN** 工具超时、返回非法响应，或 HTTP 适配返回非预期媒体类型
- **THEN** meta 显示工具出错，返回已有信息支持的答案，维持原有引用校验；不重试外部调用

#### Scenario: TD-F05 循环超限
- **GIVEN** 使用测试配置限制轮次或提议总数
- **WHEN** 模型持续提出新工具调用，包括非法提议
- **THEN** 远端发包和模型规划均受上限约束，停止工具循环，正文使用已有合法信息，状态显示超限而非伪成功

#### Scenario: TD-F06 工具注入及在途撤销
- **GIVEN** 宿主可暂停已获许可的工具调用，夹具可返回指令式文本和资源链接
- **WHEN** 一次在返回前断开或撤权，另一次用有效连接返回注入响应
- **THEN** 两次均不把结果回填或发布为成功，不打开返回链接，后续调用不绕过审批、权限或安全策略

#### Scenario: TD-N02 普通单位练习的服务端上下文
- **GIVEN** 本班已审批、启用并绑定换算工具，资料问答会话可读取授权证据
- **WHEN** 本人取得当前会话的服务端练习，携带原题面和同键发问，模型提出与练习完全一致的参数
- **THEN** 换算仅按签发值执行，结果归本人记录，资料出处仍来自合法资料，同键重放零重复调用

#### Scenario: TD-F07 非练习、改题和上下文移用
- **GIVEN** 本人取得一个短期练习上下文，另有普通提问、解题引导会话及其他班级账号
- **WHEN** 在普通提问选择换算、篡改题面或票据、跨会话或跨班移用、用错幂等键、首次受理已过期票据，或模型替换签发参数
- **THEN** 普通提问及解题引导不声明换算，票据无效或错配在流前拒绝，模型参数变化在出站前拒绝，均无换算请求
