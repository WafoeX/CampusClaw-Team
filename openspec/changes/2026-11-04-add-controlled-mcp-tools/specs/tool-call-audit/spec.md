## Purpose

让执行者追溯每次工具调用，并让教师和运维在各自的授权范围内排查问题，同时隔离私人会话、工具原文和不应保留的敏感数据。

## ADDED Requirements

### Requirement: AU-01 只增调用审计与私人边界

系统 SHALL 为每次已受理的工具提议保留唯一只增结果，记录工具标识、结果、操作者、会话及轮次、时间和耗时；不可归属提议使用脱敏类别。私人详情仅执行者可读；教师只读本班去内容元数据，运维仅可按授权读脱敏运行信息。保留、清理与恢复遵守数据规范。

#### Scenario: AU-N01 三种结果可追溯
- **GIVEN** A 班会话中分别产生一次成功、一次被拒和一次出错
- **WHEN** 执行者看自己的执行详情，教师读取本班运行视图
- **THEN** 每次提议各有一条结果，内部可追溯至操作者、轮次及时间；教师只见最小运行字段，无私人输入、结果或会话链接

#### Scenario: AU-B01 回放、断开与软删
- **GIVEN** 已提交成功的调用结果及本班连接
- **WHEN** 重放同键会话请求，断开后软删连接，再读取授权审计
- **THEN** 不重复发包或新增同一调用结果；原记录及归属不被改写，旧连接不可执行

#### Scenario: AU-F01 非法分页和篡改请求
- **GIVEN** 授权教师有可读的班内运行记录
- **WHEN** 提交非法分页、任意 class_id 或尝试编辑既有调用结果
- **THEN** 非法读请求 400/1000，记录无写入口，原结果保持一致

#### Scenario: AU-F02 角色与隐私边界
- **GIVEN** 学生有本人记录，教师无私人执行详情权限
- **WHEN** 学生访问教师运行视图，教师按 ID 读取该学生原始参数或结果，未授权运维请求查看原文
- **THEN** 学生管理请求 403/1200，教师直读私人资源 404/1300，运维未得到原文或秘密

#### Scenario: AU-F03 不存在、跨班和同班他人记录
- **GIVEN** A 班有两名学生，B 班有独立教师和学生
- **WHEN** 以同班同学或跨班身份列出并尝试直读第一名学生的记录，再对照不存在的记录
- **THEN** 私人列表不含该记录，直读同为 404/1300；本班运行视图只列授权的去内容记录

#### Scenario: AU-F04 写入故障与崩溃恢复
- **GIVEN** 可注入审计不可写及远端返回后进程终止
- **WHEN** 分别在发送前故障和已发包未追加结果时重启并恢复
- **THEN** 发送前故障不发包且标记降级；后者用稳定尝试号补唯一出错记录，不重发远端调用、不伪造成功

#### Scenario: AU-F05 秘密与恶意结果副本
- **GIVEN** 测试令牌及注入响应均带合成标记
- **WHEN** 扫描前端、Swagger、响应、日志、镜像历史和执行记录，另演练到期清理和恢复
- **THEN** 秘密和被拦截恶意原文零命中；已清理副本恢复后仍不可访问，只保留合规的去内容处置记录
