## Context

仓库已有认证与资料路由，`make check` 分别调用 Gitleaks 和 Trivy。当前秘密扫描包含本地 Git 引用可达历史及可跟踪的工作区文件，前端产物、运行日志和镜像仍需对候选单独取证。依赖检查已锁定扫描镜像并使用 `uv.lock`。异步教学和技能相关规约属于上游待取证能力，见[异步任务设计](../2026-11-04-add-async-teaching-workflows/design.md)和[助手设计](../2026-11-04-add-streaming-ai-assistant/design.md)。

## Goals / Non-Goals

- 目标是固定可复跑输入、真实判定和六份报告的归档责任，并为命令失败和权限副作用提供明确判据。
- 范围限于课程自查和报告交接。本课记录并保留真实红项，修复交后续课次。明文密钥命中时立即撤销轮换并清理历史，按事故规程留证。选做的注入检查只准备素材。

## Decisions

本规约中「课程 SEC-xx」指任务清单编号，仓库安全规范的同名编号按其原义引用。

### 冻结基线并使用正向对照

取证记录候选提交、镜像标识、Compose 项目、依赖版本、时间和脱敏夹具标识。按 README 在独立环境冷启动，固定 A/B 班数据和登录身份。同伴在最终验收 4.1 用同一候选在另一台机器独立复现。以实际路由表、OpenAPI 和获准请求为依据，避免使用约定中的路径误测未实现接口。

| 课程项 | 复测方法 |
| --- | --- |
| SEC-01 | 候选样本为 GET `/api/v1/auth/sessions/current`、GET `/api/v1/materials`、GET `/api/v1/materials/{id}`、GET `/api/v1/materials/{id}/download`、POST `/api/v1/searches`。实施时核对并登记实际方法与路径，优先补充异步状态入口。 |
| SEC-02 | 用可复现的班级专属关键词和已就绪的 A 班索引。A1 能搜到该词，B1 同模式搜索预期零条，并验证 B1 能搜到本班另一个测试词。A1 读 B 班讲义与读不存在资源比较状态、业务码、公开文案和数据。 |
| SEC-03 | 用技能、提示词、助手配置 PATCH 作为候选路径。用合法载荷和当前版本在等价夹具上证明教师可写，随后以学生重放并对比版本、配置值和副作用。清单另列实际创建、删除、审核、发布、提交和任务重放等写入面及其角色。 |
| SEC-04 | 用已知评分记录和未授权请求前后的只读快照比较提交、成绩、任务及发件箱。上游确定性评分位于正常提交事务内，若实际没有独立评分写路由，使用路由表、直接探测和快照三类证据。把课程等价确认附在该条实际记录。 |
| SEC-07 | 通过获准的应用入口执行一次技能，按关联请求和技能标识回查。逐一记操作者、技能标识、结果状态、耗时和用量（含单位），缺字段标记预计补在技能编排、审计或运行日志层。工具调用审计可用于关联，不能代替技能调用证据。 |

HTTP 复测沿用候选实际认证方式。当前认证规约用同源安全 Cookie；复测命令从本机私有环境读取口令并使用受限的临时凭据文件，公开报告只包含变量名和脱敏请求。优先比较规范化响应与数据变化，避免被 CSRF、无效载荷、空索引或错误路由产生的拒绝误导。

### 复用扫描器并分别采集退出状态

拟增 `make check-security`，共享现有扫描器、版本和阻断规则。入口应完整尝试秘密扫描和依赖审计，分别记录退出码并汇总退出状态，防止首项失败吞掉另一份基线。复用现有 Git 历史和工作区扫描，并对候选前端产物、完整测试运行日志及候选镜像做额外扫描，逐项列清资产和覆盖范围。取证前确认克隆非浅克隆及所需引用已获取，报告覆盖的引用范围和不可访问历史。扫描原始测试日志时只允许输出脱敏命中信息，公开版本不包含原始日志、Cookie 或凭据。依赖审计记录工具和数据库版本、锁文件标识及 High/Critical 分项，区分扫描故障与真实漏洞。

### 异步演示和后续课次

记录候选的实际登录、发起受理、轮询和终态链路。当前拟用教师 AI 候选题覆盖 202 和任务标识，保留可观察的 `pending → running → succeeded` 状态或上游实际状态映射，使用可控 worker 观察短暂状态。正式测验提交按现有 201 契约单列。在任课教师确认等价前，保留课程作业提交 202 的验收缺项。

事务证据以无故障的停消费者与恢复演练观察一次有效投递、一次任务完成和零孤儿任务。另测回执丢失或重放，分别统计物理投递次数、唯一任务数和唯一业务结果数。生产契约沿用至少一次投递语义。保留红项复现命令、候选版本和后续复测责任，后续归档修复前后输出与实际提交号。准备有答案、无答案、跨班三类合成问题草稿。选做 SEC-08 时准备一份含指令覆盖的讲义，以及索要提示词原文、改变评分规则、绕过权限各一条提问，供后续课堂执行。

## Risks / Trade-offs

- 上游技能、任务或索引未就绪 → 记录具体阻塞及未执行范围，保留已取得的分项结果，完成条件继续待验收。
- 课程允许书面登记漏洞处置 → 课程基线与仓库门禁分别判定，合并和发布继续遵守 SEC-16 与 REV-06。
- 命中真实密钥 → 先撤销轮换，验证旧凭据失效，再按授权协调历史及副本清理；红项和脱敏复测证据分别保留。
- 可复现红项为零 → 记录真实全绿，至少一条红项的课程条件标记为未满足，由课程方确认后续安排。

### 2026-11-05 专项与人工调度

第 8 课原文要求的真人跨机器复验保留，由项目最终验收 4.1 在全部功能完成后执行。本变更完成技术安全自查与扫描基线即可向第 9 课交接，课程完成状态等待真人结果；不把人工复验包准备写成真人已执行。各功能移交的专项攻击矩阵集中到 1.3，保留真实结果，除密钥泄漏外不提前修复。第 8 课 SEC-08 素材准备仍为选做；第 9 课明确要求四步实验，届时缺素材须补齐。
