## 1. 候选基线和权限实测

- [ ] 1.1 在异步任务收尾后固定候选提交和镜像，按 README 在隔离环境冷启动，验证 A/B 班、教师 A、学生 A1/B1 及两班可检索资料，补齐缺失的合成身份或数据。对照实际路由登记至少五个受保护接口和所有相关写入入口，保留合法请求及数据对照。验证 PSC-N01、PSC-F05。
- [ ] 1.2 执行课程 SEC-01–04。记录匿名状态码、跨班与不存在响应、跨班检索条数、学生配置写入前后差异及绕过技能的评分写入探测。按规约逐条记前置条件、操作、预期、具体实际、红绿和执行者，并写清手段、对象、判据和结果。归档 `reports/security-precheck.md` 和 `reports/risk-authz.md`，验证 PSC-F01–F05。

## 2. 资产扫描和审计基线

- [ ] 2.1 复用现有 Gitleaks、Trivy 及锁定版本建立 `make check-security`，补齐候选前端产物、运行日志和镜像扫描，在 README 写明环境、输入及分项退出判据。用隔离合成样本验证完整扫描、首项失败仍运行后项、漏扫或工具故障非零及输出脱敏，保留既有 `make check` 检查。验证 PSC-N02、PSC-F06、PSC-F07、PSC-F09。
- [ ] 2.2 在真实候选运行课程 SEC-05–06，归档 `reports/security-baseline.md`，记录各范围命中数及 High/Critical 分项和处置。命中明文凭据时立即按仓库流程撤销轮换，按授权清除历史及副本并复扫，验证旧凭据失效，保留初次红项；未清除时保留课程缺项。验证 PSC-F06、PSC-F07。
- [ ] 2.3 实际执行并回查一次技能调用，按课程 SEC-07 在预检报告逐项记录操作者、技能标识、状态、耗时、用量，每个缺失字段与拟补层级单独一行。验证 PSC-F08；受依赖阻塞的检查按 PSC-F09 记状态和原因。
