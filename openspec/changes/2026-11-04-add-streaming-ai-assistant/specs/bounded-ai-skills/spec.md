## Purpose

让教师管理班级技能并按本轮问题确定性选择一个教学流程，使内置解题引导和上传的 JSON 技能都能在明确的权限与运行预算内复现。

## ADDED Requirements

### Requirement: SK-01 受控技能管理与确定性执行

系统 SHALL 提供内置解题引导和学习计划拆解，支持教师管理受限 JSON 技能与班级启停。只有本班助手已绑定且启用的技能能参与选择，最多选一个。同分按稳定 ID 决定，零分不选。步骤 SHALL 有界、顺序执行并追溯版本，上传文本仅为数据，禁止脚本及任意调用。解题助手 SHALL 始终只给步骤提示，选用其他技能或无技能命中时同样适用，无证据时仅能使用审核通过的通用提示并标示无课内依据。

#### Scenario: SK-N01 上传、选路与顺序步骤
- **GIVEN** A 班教师保存合法两步清单并绑定助手，同时存在另一个可匹配的内置技能
- **WHEN** 学生提问使上传技能得分最高且两步均有效
- **THEN** 只选上传技能，第一步结果先于第二步，私人执行记录显示生效版本及顺序；教师无法读该记录

#### Scenario: SK-B01 同分、零分和即时停用
- **GIVEN** 同一助手绑定两个得分可控的启用技能且已有会话
- **WHEN** 依次发起同分提问、停用胜出技能后再问原题、提交零分提问
- **THEN** 依次选较小稳定 ID、仅剩的匹配技能、不选技能；无需新建会话

#### Scenario: SK-B02 无课内证据的解题引导
- **GIVEN** 解题引导被选中且授权检索成功但没有证据
- **WHEN** 学生请求直接给最终答案
- **THEN** 只显示受控通用步骤、无课内依据提示、空出处，无最终答案；资料问答模式对同一问题走上游固定文案且零对话模型调用

#### Scenario: SK-F01 非法或重复清单
- **GIVEN** A 班教师有技能写权限
- **WHEN** 上传含重复键、未知字段、脚本、越界步骤、非法工具名或班内同名的清单
- **THEN** 400/1000，有可读错误，无定义、修订、绑定、脚本或外部调用副作用

#### Scenario: SK-F02 学生绕过管理页面
- **GIVEN** A 班学生知道技能管理接口
- **WHEN** 发出创建、修改、启停或删除请求
- **THEN** 403/1200，无版本、启用和绑定变化

#### Scenario: SK-F03 外班技能和缺失技能同构
- **GIVEN** A 班教师知道 B 班技能 ID
- **WHEN** 分别按外班 ID 和缺失 ID 读取或绑定
- **THEN** 404/1300 同构，无技能描述泄露和写入

#### Scenario: SK-F04 中途依赖故障
- **GIVEN** 选中一个三步技能且第二步网关持续超时
- **WHEN** 运行技能直至预算耗尽
- **THEN** 暴露 1500 安全错误，第三步零调用，无成功助手消息，只保留脱敏失败诊断

#### Scenario: SK-F05 不可信指令和解题答案泄露
- **GIVEN** 上传步骤包含越权指令，替身输出含非允许槽位和最终答案
- **WHEN** 在解题助手中分别以该技能、内置解题引导及无技能命中运行
- **THEN** 上传文字仅作为数据，越权工具零调用；解题路径不将自由文本、最终答案或非法槽位发送给浏览器或写入可回读结果
