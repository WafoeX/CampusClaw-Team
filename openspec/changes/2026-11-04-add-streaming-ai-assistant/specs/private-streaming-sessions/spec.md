## Purpose

为班内师生提供仅本人可访问的持久会话、消息与执行记录，使用真实增量 SSE 回答并核对出处，在故障、断流和重复请求时维持可验证的一致结果。

## ADDED Requirements

### Requirement: ST-01 受授权的增量会话和幂等完成

系统 SHALL 仅允许当前班级中的本人创建、列出及读取会话和执行记录。每轮 SHALL 重读当前配置并以本轮问题和班级、章节、绑定材料交集检索；资料问答无合法证据使用固定文案、空出处且零对话模型调用。系统 SHALL 通过第 3 课同源 Cookie 会话和写入防护下的 POST SSE 按 meta、增量 delta、done 或 error 的次序传输，公开增量必须先校验，done 只在助手消息、最终出处和成功执行记录已提交后发送。断流和同键重试不得产生重复用户消息、成功回复或成功执行记录。原单次问答 SHALL 继续遵守 QA-01。

#### Scenario: ST-N01 真实流和本人回读
- **GIVEN** A 班学生选择本班启用助手，章节和材料绑定交集有两片可授权证据，模型替身可暂停第二段
- **WHEN** 携带有效同源会话与规定的写入请求头发起 POST，观察第一段后再放行第二段并随后读取消息和执行记录
- **THEN** 先见 meta，再见多个新增文本 delta，第二段放行前第一段已达；拼接文本等于持久正文，最终编号可核对，唯一 done 之前事务已提交

#### Scenario: ST-N02 保持单次问答契约
- **GIVEN** 有本班材料和新版会话功能
- **WHEN** 执行第 4 课单次问答正常、无证据及依赖故障场景
- **THEN** 继续满足 QA-01 的公开响应、证据预算、错误与副作用，未新增会话、消息或本课执行记录

#### Scenario: ST-B01 历史与检索边界
- **GIVEN** 会话已有 8 条完成消息且含超长历史，其他章节、未绑定和 B 班资料含不同特征词
- **WHEN** 学生选 A 班章节提问，再测试无合法交集的资料问答
- **THEN** 只拿本轮问题检索，最多 4 片共 12000 码点且都在交集；历史至多最近 6 条、每条至多 500 码点；无交集固定文案、空出处、零对话调用

#### Scenario: ST-B02 助手停用与下一轮配置
- **GIVEN** 学生已有会话，教师更新材料绑定后停用助手
- **WHEN** 学生分别在更新后和停用后对原会话提问，再用停用助手新建会话
- **THEN** 原会话先使用新绑定，停用后使用默认角色与空绑定，记录可核对有效修订；新建与缺失助手同为 404/1300

#### Scenario: ST-F01 非法提问与重复键冲突
- **GIVEN** 有可访问会话和已受理的幂等键
- **WHEN** 发送空问题、越界问题、缺键、伪造班级或用同键提交不同输入
- **THEN** 参数错误 400/1000，键冲突 409/1400，无新增模型调用、消息或成功记录

#### Scenario: ST-F02 无有效认证
- **GIVEN** 合法会话存在
- **WHEN** 匿名请求或携带已过期、已撤销会话的请求尝试发问及读取执行记录
- **THEN** 401/1100，无流头、内容、出处及写入

#### Scenario: ST-F03 私有资源枚举
- **GIVEN** A1、同班 A2、A 班教师及 B 班学生账号
- **WHEN** 后三者分别列表、按 ID 读 A1 会话或执行记录并发起消息请求，再用不存在的 ID 比对
- **THEN** 列表无 A1 资源，直接访问 404/1300 同构，无任何私有字段、模型调用或写入

#### Scenario: ST-F04 流前和流内依赖故障
- **GIVEN** 本班有证据，分别注入检索故障与首段之后的网关超时
- **WHEN** 发起两次流请求
- **THEN** 首次为 HTTP 503/1500、无 SSE；后一次是 meta、已校验 delta、唯一 error(1500)，无 done，界面清除未完成预览且没有可回读的成功助手消息

#### Scenario: ST-F05 无效段落与受保护答案
- **GIVEN** 模型替身返回越界编号、错误数值或尝试通过提示注入读取未开放答案
- **WHEN** 检查网关请求、原始 SSE 及回读数据
- **THEN** 输入未含答案源或未授权资料；无效内容不得出现在 delta、最终消息、回放或私人记录，无效输出发 error(1501) 且无 done

#### Scenario: ST-F06 断流、并发与提交回执丢失
- **GIVEN** 同一轮可暂停在事务提交前或提交后发送 done 前
- **WHEN** 并发重放同键，模拟提交前断开并在失败确认后重试，另对已提交但丢帧的成功请求按键回放
- **THEN** 在途同键 409/1400；未提交可按规则重试且复用用户消息；已提交按当前授权回放，模型无额外调用，每轮仅一个成功消息和成功执行记录

#### Scenario: ST-F07 生成期间配置或授权变化
- **GIVEN** 第一段已发送且另一段正在生成
- **WHEN** 停用绑定技能、撤销调用者权限或变更已选证据的发布版本，再让模型继续
- **THEN** 流终止并清除预览，新增段落和成功消息均未发出，后续读取按当前权限判定
