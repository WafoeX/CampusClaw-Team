# 第 4 课技术设计

## Context

见[提案](proposal.md)。复用第 3 课的当前数据库身份、同源 HTTPS Cookie 会话与写入防护、稳定 UUID、原文版本、元数据修订号和 MySQL 原文字节；正文当前不可通过 PATCH 修改。第 3 课的 [CA-04](../2026-11-04-add-class-auth-material-ingest/specs/class-auth-material-ingest/spec.md) 需先进入主规格，才能合入本变更的完整修改条款。当前 Compose 固定 MySQL 8.4 和 Qdrant 1.15.3，仅应用映射宿主端口；Qdrant 不可达时骨架 /health 为 200 且 degraded。

## Goals / Non-Goals

把权限与发布状态的事实源留在 MySQL，并使同一证据可以按版本定位原文。索引处理与请求入口分离，以便更换执行方式；本课不引入后台调度器、历史快照存储或模型工具权限。

## Decisions

### 1. 章节、页面与授权

| 入口 | 允许角色、资源与成功行为 |
| --- | --- |
| GET /api/v1/chapters | 本班师生；按 (sort_order, id) 返回真实章节和单独的未分类入口 |
| POST /api/v1/chapters；PATCH/DELETE /api/v1/chapters/{id} | 本班教师；创建 201/0、改名或调序及删除 200/0；删除时将本班关联资料原子移回未分类 |
| GET /api/v1/chapters/{scope}/materials | 本班师生；按 (sort_order, id) 分页，scope 为本班章节 UUID 或保留字 uncategorized |
| PUT /api/v1/materials/{id}/chapter-assignments/current | 本班教师；传 chapter_id（UUID 或 null）和当前元数据修订号，200/0；变更归类只推进元数据修订，不重建索引 |
| POST /api/v1/materials/{id}/index-builds | 本班教师；创建有界构建，返回版本和状态；成功 201/0，失败按下文状态契约 |
| GET /api/v1/materials/{id}/index-builds；GET /api/v1/materials/{id}/index-builds/{build_id} | 本班教师；列出最近构建或读指定构建状态及脱敏故障阶段，缺失或已撤销 404/1300 |
| POST /api/v1/searches；POST /api/v1/material-answers | 本班师生；分别传 query 或 question、可选 mode 与 chapter_scope；同步返回结果，不创建历史记录 |
| GET /api/v1/materials/{id}/citations/{chunk_id}?index_version=…&source_version=… | 本班师生；已授权且版本一致才返回定位资料，固定按提交的版本查找 |

- /chapters 集中展示章节目录、浏览和教师管理操作；/materials、/materials/{id} 继续浏览和定位原文；/console 管索引；/search 和 /ask 使用同一范围选择组件和出处卡片。沿用第 3 课内存认证导航。加载、正常、错误、空四态；检索无命中独立提示；问答无命中正文固定“资料中未找到相关内容”，界面可另附下一步。未知路由 404，所有新增方法显式登记，无匿名例外。复用组件和视觉令牌，校验提示关联字段，提问仅提交校验，写入中禁止连点；键盘、两档屏宽、标签、焦点和对比度按 PROD-03–10 走查。
- 一个资料最多一个章节；空外键即未分类。旧资料和新上传均默认空，未分类不占章节行，始终置于真实章节后。省略 chapter_scope 为本班全部（含未分类），显式 uncategorized 只查空外键；空串、null、未知字段、非法 mode 返回 400/1000；外班和缺失的合法章节 ID 同为 404/1300，不得扩大范围。默认检索 keyword、问答 hybrid；查询和问题去首尾空白后 1–4000 个 Unicode 码点。章节名去首尾空白后 1–120 字符，“未分类”为保留名；排序为 0–1000000 整数；列表 page 默认 1，page_size 默认 20、最高 100，非正整数拒绝。章节内归类与删除锁定相关章节/资料行并校验归属；移回未分类时推进受影响资料的修订号，阻止迟到覆盖。
- 统一 X-Request-ID、code/message/data/request_id，敏感响应 no-store。身份→功能权限→参数→资源归属→状态；写入事务重校身份与归属。未知 class_id/role 请求字段拒绝，伪造身份头无效；学生写 403/1200，未登录 401/1100，资源越界与不存在均 404/1300，事务竞争 409/1400，依赖 503/1500、结构或引用无效 502/1501，配额 429/1600。业务服务划定短事务，仓储使用参数绑定；外部 SDK 只出现在适配器。
- 创建章节、归类和发起构建采用第 3 课格式的 Idempotency-Key，按班级、操作者、方法及资源、键唯一，24 小时内同指纹重放已提交受理/终态，无重复副作用，异指纹 409；处理中重放返回 200/0 和相同构建 ID、当前阶段。重试失败构建须用新键、新索引版本；幂等重放先校当前授权，资源删除后不再返回原结果。章节 PATCH/DELETE 以当前修订号做条件写入；同值且当前修订相符不写，过期 409，重复删除 404。

### 2. 原文、切片和两个存储

- 原文坐标以第 3 课解码预览规则为准：严格 UTF-8，忽略开头一个 BOM，保留 CRLF、空白和组合字符，不做 Unicode 归一化；0 基 Unicode 码点半开区间 [start,end)，不可用字节偏移或浏览器 UTF-16 偏移。切片文本严格等于该版本原文区间；浏览器按码点换算高亮。编号是版本内 ordinal，稳定身份为按固定命名空间由 (material_id, index_version, ordinal) 生成的 UUID，构建重放使用同一点 ID；不得跨版本复用。
- 自动模式优先段落/行末，长段按字符窗口回退，拟定窗口 600、重叠 80；自定义使用教师指定窗口（100–1200）与重叠（0–min(200, 窗口-1)），步进至少 1；最后窗口达末尾停止，去掉纯空白切片，不裁改非空文本。标题模式仅支持 Markdown，使用固定解析版本识别 ATX/Setext 标题并忽略围栏代码内伪标题，以标题行起点为分界、保留标题前正文，超长区间在本段内用自动规则，Markdown 无标题回退自动。原文不写回。单次构建上限 64 片。所有模式在建立构建记录前检查原文不超 32,000 码点，超限 400/1000，提示按章节拆成多份资料，原文仍可预览下载。自动模式的段落策略超 64 片时回退固定 600/80 窗口，此时覆盖 32,000 码点至多 62 片；标题/自定义超片数时提示改用自动模式，不发布截断资料。
- MySQL 存 chapters、material_index_builds、material_chunks 和去内容索引清理记录，沿用原文表。章节与资料用同班组合外键，移回未分类在事务内完成。构建记录含 build_id、class_id、material_id、source_version、单调 index_version、index_config_version、状态、阶段、租约截止和幂等关联；切片有 UUID、版本、序号、区间及正文，版本+序号唯一。资料有可空 active_index_version、desired_index_version，以及活动版本的 vector_ready 标记；记录 UTC、创建人及去内容审计。MySQL InnoDB utf8mb4 切片正文建 FULLTEXT WITH PARSER ngram，在 MySQL 启动配置锁定 ngram_token_size（拟 2），迁移登记排序规则和停用词配置；以绑定参数的自然语言 MATCH AGAINST 排序，零分排除，过短或纯标点查询可能无命中，禁止临时全库 LIKE 扫描。参考 [MySQL ngram 文档](https://dev.mysql.com/doc/refman/8.4/en/fulltext-search-ngram.html)。
- Qdrant 仅保存向量及一致性字段：点 ID 等于 chunk_id，payload 为 chunk_id、class_id、material_id、source_version、index_version、index_config_version 和可精确匹配的版本作用域键；不存正文、不存章节，章节归属永远取实时 MySQL，移动无需回写 Qdrant。对过滤字段建 payload 索引，集合绑定嵌入模型版本、维度和距离函数，发布前确认写入完成并核对点数、标识、payload、维度及有限值。参考 [Qdrant 点文档](https://qdrant.tech/documentation/manage-data/points/)。Qdrant 只经应用与 Qdrant 共用的私有 Compose 网络访问，不映射端口、不暴露控制台或前端密钥。依赖地址走部署白名单，禁止客户端提供地址或通过重定向越过允许目标。

### 3. 有界构建、可见性和补偿

1. 原文先按第 3 课提交。未构建资料状态为待索引；教师工作台在上传成功后可用同一构建入口启动首次自动切片，教师也可从待索引列表启动/重试。直调原文上传 API 保持原契约，不暗起后台工作。接口只同步执行本次有界构建；状态可由授权教师在另一请求查询。
2. 短事务预留构建 ID 与单调版本，置为 desired；跨进程以数据库约束/租约确保每班同时一个构建（冲突同资料 409、班级额度 429）。pending → building → published / keyword_only / failed / superseded（keyword_only 为已发布关键词但向量未完成的终态）；持久化阶段并设置执行截止。切片计算、嵌入和 Qdrant I/O 在事务外；暂定最多 64 片、每批最多 32 片、全流程 35 秒含重试，单模型调用 ≤15 秒且仅瞬态至多重试一次、退避 1 秒，剩余预算不足则停止；下游与 WSGI 请求预算须匹配，停机仍沿用 30 秒排空，超出靠失效租约恢复。运维登记请求量、错误率、P95、积压与依赖告警负责人，断依赖时核对降级与处置。
3. MySQL 切片全部写入后，在短事务内校验资料、原文版本、desired、配置、租约和教师权限。首次构建或旧版仅关键词时，可切换关键词指针并标记 keyword_ready；随后核对全部向量后将同一版本置为 vector_ready。已有完全就绪版本时，新切片与向量全部核对后才切换指针。向量失败只清理失败向量，保留已发布关键词；按新构建版本显式重试，旧关键词可在替换前继续服务。正文变化与删除同事务撤销两种可见性，迟到任务不得推进指针。
4. 删除按 CA-04 同事务撤销访问、删除原文/切片并写不依赖被删外键的清理凭证；提交即 200/0，失败全回滚。事务外清理旧版本或删除资料全部精确版本键的向量；不以宽泛班级过滤执行删除。清理可在操作后剩余预算内尝试或由运维运行显式有界补偿命令；无持续后台线程。失败持久记录阶段、尝试次数、下次时间；拟每条最多 3 次自动尝试、退避 1/5/30 分钟（由显式批处理在到期时执行），每批 100 条，耗尽进入人工处理。成功须以查询确认残留清除。删除清单保留至覆盖备份和在途写入窗口；对超时、回执不明与迟到 upsert 保持待复核，核对写方退出/租约以及向量端写入收敛，再反查并重删孤儿。迟到向量即使落库也不能改变 MySQL 指针。运维须登记补偿执行频率和处理人。
5. 向量失败时同步构建返回 503/1500 并标明关键词是否已就绪；其他失败返回 503/1500 或对应参数/冲突码，必要时 data 只附已受理的 build_id 和安全状态，教师状态入口展示阶段、重试建议及请求标识。崩溃后显式恢复器把过期 building 判为失败并登记回收；不无限等候。第 8 课仅替换调度入口：同一 prepare/run/publish/cancel/cleanup 业务边界，任务键含资料 ID、原文版本、索引配置版本和构建 ID，携带授权发起者标识但不持久化令牌；执行/发布重新验证当前身份，版本/租约 CAS 和删除补偿保持有效。

### 4. 三路召回与出处

- 每次从当前身份的 class_id 开始，将请求 chapter_scope 与本班有效章节/资料求交。关键词 SQL 在排序取限前联查当前归属、原文版本及发布指针；仅关键词路径不访问嵌入或 Qdrant。向量先从 MySQL 获得授权且 vector_ready 的精确版本作用域键；若选定范围包含仅关键词已发布资料，向量或混合查询返回 503/1500 并提示改用关键词或缩小范围，过滤须同时匹配班级和这些键，再以固定嵌入和阈值召回；无作用域键不能发无过滤查询。拟定向量作用域最多 1000 个已发布资料版本，越界返回 429/1600，请缩小章节；不截断后伪称查完。合法向量/混合请求在向量依赖不可用时统一 503 并提示改用关键词（空作用域也检查向量服务可用，不发无范围点查询）。
- 向量命中批量回表，核对真实切片 ID、全部版本/作用域字段和实时资料、章节、当前身份；丢弃错配、越界或失效候选，在有效候选上排名，不返回丢弃数量给调用方。混合并行/同一总预算执行两路，任一路失败都不冒充混合成功；按 chunk_id 去重，用 RRF Σ1/(k+rank)，两路各自从 1 开始、缺一路计 0，同分用 chunk_id 稳定打破。向量及关键词各路原始分数不直接相加；拟定每路召回 20，结果最多 8，k 拟 60。合成对照固定该配置或经隔离调参后锁定，报告实际值；阈值依真实嵌入确定，缺登记不发布。故障、配额和真实空命中分别报告。
- 返回真实标题、资料 ID、切片 ID、原文/索引版本、字符区间和该区间文本；结果/出处响应前复核授权和当前范围。重建或删改发生于模型在途时，返回前重新校验证据全集及当前身份；证据版本或范围已变则 409/1400 并重试，身份无效 401、缺失或越界不泄露内容。单次回答的出处卡持有当次版本，授权出处入口先验资料和可读归属，资料已删或跨班为 404；本班资料仍在但出处属于其已撤销的真实旧构建版本，回 409，提示来源已重建且不跳新片段；未知切片或伪造版本配对为 404。构建清理时旧切片只保留去内容的 ID 与版本映射，按留存清理；过期映射按未知出处返回 404。

### 5. 单次问答与评测

- 仅当前问题作为查询。成功召回后最多取 8 个完整切片、证据合计不超 12000 码点，按排序取预算内连续前缀，按实际送入的证据从 1 编号。材料、模型输出及标题以纯文本渲染，出处按钮仅从服务端验证过的 ID 和版本构造同源地址。没有合法证据返回 200/0、固定文案、空 citations，且对话网关调用为零。有证据才把问题和不可信证据作为用户消息数据，系统模板固定版本、禁执行资料指令、禁工具和外部知识。模型输出结构化结论及对应证据编号；编号必须属于本次映射，每条主要结论至少一个编号，出处完全由服务端生成。模型可结构化声明证据不足，服务端返回同一固定文案和空出处，但须与检索无命中分开记录。
- 对结论中的适用数值（明确数量、比例、带单位量）以关联片段校验值、单位及对应字段/语境；支持可明确验证的等价格式（如 20% 与 0.2 在同一比例语境），不验证无规则的推导则拒绝包含该推导的输出。编号、引用、适用数值或结构校验失败返回 502/1501，不回传未通过答案，不自动重试非瞬态错误。程序校验不替代人工判断主要结论是否受证据支持。
- 集中登记检索/切片配置版本、嵌入与对话模型实际标识、维度、阈值、RRF、版本化系统模板、温度 0.2、最大输出 2048 token、单模型调用 15 秒与总预算 35 秒。每用户模型调用暂定 6 次/分钟、并发 1，含实际重试；超过配额 429。普通资料/章节查询按 OPS-11 的固定数据 1000 条、并发 10 验证 300ms 标记、1000ms 硬档；含模型路径按 AI-08 的 8 秒标记、35 秒硬档另计。运行日志仅记录阶段、脱敏标识、版本、命中数、耗时、用量和故障类；不含问题、答案、片段、凭据或原文。未定模型/阈值和所有暂定限值由实施人用隔离夹具、真实网关及容量验证，记录配置和人工确认后冻结。
- 最终集至少 30 个互不重复、人工标注的问题，拟 8 直接事实、8 同义、8 跨片段、10 无答案；独立调参集不得与最终集或其改写重合。先固定资料快照、问题、答案要点、对应资料版本及标注区间/片段（跨片段记录证据组合）、无答案依据，冻结并留版本摘要；相关性以人工确认的冻结切片映射判定。跨班安全样本及 AI-11 工程回归单列，不混入课程分母。使用合成或授权脱敏资料，两名组员标注/复核争议，保留分歧和裁决。
- 三模式用同一语料、问题、授权、切片与版本、对话模板、模型和配置；固定机器、容器版本、网关、并发与预热策略；三模式按固定轮换顺序记录，不择优删样本。每题每模式独立检索和问答各一次，端到端从请求发出至完整响应；预热不计，记录失败样本和时长。各模式分别报有答案题 Hit@5（前 5 条有效结果至少命中一个标注相关片段的题数/全部有答案题）、依据充分率（主要结论正确且均由所列出处支持的题数/全部有答案题）、无答案处理正确率（固定不足提示且空出处、无伪答的题数/全部无答案题）。漏答、错误和依赖失败留在对应分母且不得计为成功；另报跨片段题在前五覆盖任一完整标注证据组合的题数与比例；短词、单字、公式和缩写用真实 MySQL ngram 独立复核，结果区分无命中和配置缺陷。分别报检索/问答样本数、失败率、中位数（偶数取中间两值均值）和 P95（排序第 ceil(0.95n) 项），纳入所有实测尝试含超时。记录逐题结果、前五 ID、脱敏人工判定及理由、调用/耗时、失败原因和实际与 80%/90%/90% 目标差距；安全与引用是硬门禁，效果数字按实际报告，不预设混合占优。

## Risks / Trade-offs

- 首次完整的 MySQL 切片可独立服务关键词。向量故障由教师界面标出，已有完全就绪版本的重建仍以同一版本成对切换。
- 有界同步方案牺牲超大资料的一次性索引容量。对切片超限明确失败并允许调整配置；后台化不改变版本和授权契约。
- Qdrant 不参与数据库事务；通过发布指针、精确过滤、回表和独立补偿控制可见性与副本收敛，不把远端删除成功作为原文撤权的前提。
