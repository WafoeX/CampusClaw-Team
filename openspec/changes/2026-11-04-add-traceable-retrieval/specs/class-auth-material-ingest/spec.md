## MODIFIED Requirements

### Requirement: CA-04 授权下载与清理

系统 SHALL 以资料 ID 定位原文，每次下载在返回任何附件头或字节前完成授权；附件按原字节、服务端安全命名返回。预览把文字和 Markdown 当不可信纯文本显示。教师删除在一个事务内撤销访问并清理正文及元数据，同步成功后不再可读。删除同事务撤销发布指针、清理本地切片并登记去内容的索引清理凭证；提交后任意索引、出处和迟到构建均不得复活该资料。向量在事务外按精确版本清理，失败可有界重试且不撤销原文删除。删除后的备份按数据与运维规范隔离轮转，恢复前补做删除核对。

#### Scenario: IO-N01 合法预览、下载和删除
- **GIVEN** A 班有两份不同来源的资料，教师和学生均已登录
- **WHEN** 学生预览及下载两份资料，教师随后删除其中一份
- **THEN** 预览为 200/0，下载为 200 且附件字节与入库原文一致；删除为 200/0，被删资料的两张表均无对应行，列表、详情和下载均不再提供该资料，另一份仍可读

#### Scenario: IO-B01 预览的脚本与危险链接
- **GIVEN** 本班资料含脚本标签和危险链接文本
- **WHEN** 师生预览并下载
- **THEN** 页面展示文字且不执行脚本或生成危险链接，下载字节与原文相同

#### Scenario: IO-F01 不存在与重复删除
- **GIVEN** 一份资料已成功删除，另一份资料仍存在
- **WHEN** 重复删除前者，再用其 ID 请求下载
- **THEN** 均为 404/1300，无附件头或新副作用，仍存在的资料不受影响

#### Scenario: IO-F02 删除事务中断
- **GIVEN** 教师可删除本班资料，已注入删除一张表后提交前的数据库故障
- **WHEN** 发起删除、解除故障后读取并重试删除
- **THEN** 首次为 503/1500 且恢复后两行与下载原文完整，既有发布指针及切片完整且未写成功清理凭证；重试为 200/0 且两行和切片共同消失，目录始终无变化

#### Scenario: IO-F03 下载依赖故障
- **GIVEN** 本班学生身份有效，资料库在获取原文时故障
- **WHEN** 请求下载
- **THEN** 返回 503/1500 JSON，无附件头或部分原文字节

#### Scenario: IO-F04 非法标识及越权写入
- **GIVEN** 本班有资料且分别持有教师、学生令牌
- **WHEN** 教师下载非法格式 ID，学生尝试删除本班资料
- **THEN** 分别为 400/1000 和 403/1200，均无附件及数据库或文件副作用

#### Scenario: IO-N02 删除后索引立即不可见
- **GIVEN** 本班资料有已发布切片并持有当次出处
- **WHEN** 教师删除后，学生请求三模式检索、下载和原出处
- **THEN** 删除 200/0，原文及切片行不再可读，三模式均不返回该资料，下载和出处 404/1300；向量清理完成后反查无该资料残留

#### Scenario: IO-F05 删除与重建并发、清理失败
- **GIVEN** 资料重建在途，Qdrant 删除会失败，迟到的 upsert 仍可能完成
- **WHEN** 教师删除，释放在途写，恢复 Qdrant 并运行补偿两次
- **THEN** 删除仍为 200/0；三路不能返回该资料，迟到发布不复活原文或索引，保留可重跑清理凭证；补偿最终无残留，不影响同班其他资料或外班向量
