## Purpose

为单班级师生提供稳定的章节目录、资料归类和浏览入口，使教师可以组织课程材料，学生可以在当前班级授权范围内查找原文。

## ADDED Requirements

### Requirement: CH-01 班内章节管理与浏览

系统 SHALL 仅允许当前本班教师创建、改名、排序和删除章节及归类本班资料。本班师生可浏览。一个资料最多属于一个章节，既有和新资料默认未分类，删除章节时其资料同事务移回未分类并保留原文。章节和资料各按顺序、ID 稳定排序。

#### Scenario: CH-N01 组织章节并浏览
- **GIVEN** A 班有教师、学生与两份未分类资料，B 班有其自己的目录
- **WHEN** A 班教师创建两个章节、改名并调序，将一份资料归类，学生打开章节和未分类列表
- **THEN** 创建 201/0、修改与浏览 200/0；章节顺序与设置一致，两份资料各在正确入口出现，所有列表和总数均无 B 班信息，原文版本不变

#### Scenario: CH-B01 同序和删除章节
- **GIVEN** A 班两章同序且其中一章有资料
- **WHEN** 学生重复浏览，教师按当前修订删除有资料的章节，学生再打开未分类
- **THEN** 同序按 ID 稳定；删除 200/0，旧章节 404/1300，受影响资料可按原字节下载，归入未分类且其元数据修订推进

#### Scenario: CH-F01 非法输入
- **GIVEN** A 班教师已登录
- **WHEN** 创建空白名或排序值为 1000001 的章节，再以非法 UUID 提交归类
- **THEN** 均为 400/1000；章节、资料修订及归属均无变化

#### Scenario: CH-F02 学生和匿名写入
- **GIVEN** A 班学生有效且知道本班资料及章节 ID
- **WHEN** 用学生身份带伪造教师头尝试创建、修改、删除及归类，再无令牌重放
- **THEN** 分别为 403/1200 和 401/1100，数据库无变化且不泄露资源数据

#### Scenario: CH-F03 外班与缺失资源同构
- **GIVEN** A 班教师和学生有合法的 B 班章节 UUID 及一个未分配 UUID
- **WHEN** 分别浏览两 ID，教师分别改名、删除和将本班资料归入两 ID；再尝试归类 B 班资料
- **THEN** 全部 404/1300，文案和 data 同构；不返回标题、数量或正文，无归类副作用

#### Scenario: CH-F04 删除事务中断
- **GIVEN** A 班教师能删除含资料的章节，且可在归类清空后、提交前注入数据库故障
- **WHEN** 删除，随后恢复数据库并检查原目录和修订，再以原修订重试
- **THEN** 首次 503/1500，章节和资料归类、修订均未部分改变；重试 200/0，章节消失且资料进入未分类

#### Scenario: CH-F05 重放与过期修订
- **GIVEN** 两名本班教师读取同一资料修订
- **WHEN** 一人归类成功并同键重放，再换内容重放；另一人用旧修订提交另一归类
- **THEN** 相同请求返回同一业务结果且只推进一次修订，异内容重放及旧修订写入均 409/1400
