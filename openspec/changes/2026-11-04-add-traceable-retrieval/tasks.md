# 第 4 课实施任务

本轮只提交规划。按依赖逐组实施，各组实测留证后才勾选。实施人负责代码和验证，AI 实施人负责配置、评测与取证，运维负责隔离环境及恢复，另一成员负责人工评审，课程联络人核对课程口径；实名由小组指定。

## 1. 前置与章节

输入：已验证可运行的开发骨架、第 3 课资料和认证基线、A/B 合成夹具。输出：班内章节和归类。

- [ ] 1.1 核对上游启动、门禁、当前数据库身份、原文版本、撤销和 A/B 隔离证据；合入 CA-04 增量前复核第 3 课同步至主规格的完整条款并重跑本变更严格校验。课程联络人核对第 4 课必交项与首次索引触发方式，记录正式依据；有差异先修订规约。确认主干保护与适用必需门禁后再编码。
- [ ] 1.2 用 `project-data-change` 先登记字典、学期及清理责任。新增章节及同班归类迁移；真实 MySQL 空库/旧库/重跑和回退验证既有资料为未分类且下载字节不变。
- [ ] 1.3 实现章节管理、稳定排序、按章节/未分类浏览与条件归类，接入既有内存会话和四态界面。接口与真实 MySQL 断言 CH-N01、CH-B01、CH-F01–F05，覆盖另一班和缺失同构、事务回退及并发重放。

## 2. 构建与删除

输入：已验收章节与原文契约、隔离 MySQL/Qdrant、经确认的切片、限额和模型配置。输出：可定位切片、双库发布与清理补偿。

- [ ] 2.1 登记切片、全文、Qdrant payload、构建状态和清理凭证字典，新增兼容迁移及 ngram 索引。在真实 MySQL 测中文查询与排序、验证空库和旧库重跑。用单元样本验证 BOM、CRLF、补充字符、三种切片、版本 ID、原文定位及参数和容量边界（IX-N01、IX-B01、IX-B02、IX-F01），覆盖 32,000/32,001 码点、固定窗口回退和拆分提示。
- [ ] 2.2 接入有界构建、教师状态和重试界面，落实锁、租约、事务外副作用、配置指纹、发布 CAS 与第 8 课复用接口。真实 MySQL/Qdrant 验证 IX-N01、IX-B01、IX-F02–F05，包括点错配、部分写、停机恢复、重复请求、权限撤销与迟到发布。
- [ ] 2.3 接入 CA-04 删除撤权、旧版本和失败构建的精确清理、运维有界补偿和恢复防复活。故障注入验证 IO-N01/N02、IO-B01、IO-F01–F05 和重建并发；检索接通后复测三模式。用隔离副本验证迁移回退、删除凭证重放和迟到向量收敛。

## 3. 三路检索与出处

输入：已发布版本、当前身份和 A/B 两班资料。输出：三模式和可打开的出处。

- [ ] 3.1 实现范围求交、SQL 中文全文、精确向量预过滤及回表验权、RRF 去重和稳定排名。以 RT-N01、RT-B01、RT-F01–F04/F06 验证替身和真实依赖；检查跨班唯一关键词、伪造参数、无过滤调用禁止、向量/混合失败及关键词仍可用。
- [ ] 3.2 接入检索页、出处卡及授权定位，使用代码点区间高亮。走查 RT-N01、RT-F02/F03/F05 和 IO-N02/F05；对照旧出处不重指、已删出处不可读、章节变化后实时范围与响应前重验。验证 Qdrant 无宿主机端口映射。

## 4. 单次问答

输入：已验证授权检索及真实网关测试配置。输出：单次有限证据问答和确定性失败契约。

- [ ] 4.1 实现证据预算、编号映射、版本化模板、网关超时/配额、引用与适用数值校验、回答前复核。用隔离替身验证 QA-N01、QA-B01、QA-F01–F06：断言空命中和检索故障时零对话调用，覆盖恶意材料、伪引用、数值与单位不一致、生成期间证据失效和无会话写入。
- [ ] 4.2 接入 /ask 章节和模式选择、无命中与错误状态、出处交互。浏览器走查登录→章节→检索→单次问答→出处，核对键盘和两档宽度。以真实网关做最小授权、有限证据和时延验证；分开保存确定性替身与真实依赖证据。

## 5. 评测与交付

输入：四组核心功能及各组场景通过的证据。输出：工程回归、课程评测和可审阅记录。

- [ ] 5.1 用 `project-prompt-eval` 建 AI 规范固定回归（初始 10 条应答、10 条应拒答），另建独立调参样例、至少 30 题冻结人工标注最终集和单列跨班安全用例。评审标注与集合隔离，记录参数冻结前后、同条件三模式的 Hit@5、依据充分率、无答案处理和两类时延中位数/P95，保留失败；脱敏报告归入 `docs/eval/YYYY-MM-DD-<版本>.md`。实验页面仅核心验收后另行择项。
- [ ] 5.2 用 `project-add-tests` 和 `project-review`，按场景双向核对正常、失败及边界。执行 `make check CHANGE=2026-11-04-add-traceable-retrieval`、应用 pytest、独立 Compose 冷启动/故障恢复、真实 MySQL/Qdrant 集成及浏览器；按评审协议在授权隔离环境确认移除授权或发布版本检查会使对应断言失败，恢复后复测。同步 README、页面清单、API 契约与数据字典，归档实际命令和结果，提交人工评审。
