# CampusClaw 项目最终验收

## Why

小组和课程评审需要确认同一个候选版本能跑通教师与学生的完整教学流程。各实现变更的测试证明本次改动符合规约，最终验收用实际候选版本核对多个功能接在一起后的结果。

## What Changes

- 各实现变更交付时完成适用测试、合并门禁和人工评审，记录对应提交及结果。
- 核心功能齐备后，在独立环境验证同一候选版本的资料入库、检索问答、练习与测验闭环，汇总发布就绪证据和实际评审结论。
- 发现问题时记录复现步骤并交由对应实现变更修复。以修复后的同一候选复验受影响的链路。

## Capabilities

本变更组织验收与证据交付，沿用各功能的业务规约。

## Impact

依赖骨架和核心业务变更的可运行交付、各自的测试证据及课程记录。验收以项目 README 的核心用户流程为范围，功能范围以届时批准的业务规约为准。
