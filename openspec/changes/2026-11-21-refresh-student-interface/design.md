## Context

班级、教学和试调模板已共用带 CSP nonce 的样式。登录模板另有颜色和表单定义。更新涉及两套页面外壳和所有共用表单控件。

## Goals / Non-Goals

**目标**：统一色彩和焦点规则，突出中学生经常使用的入口、表单和页面标题。沿用页面清单和四态文案。

**范围**：现有页面模板及样式。路由、脚本数据流、权限、数据结构和工具配置沿用当前契约。

## Decisions

- 在现有 nonce 样式入口维护靛蓝主色、薄荷选中态与独立的错误色，登录页复用这些令牌和控件。单页配色覆盖会形成两套焦点与状态规则，故统一定义。
- 桌面保留侧栏，窄屏用可换行的导航网格。评估过折叠菜单，保留可见入口可以复用原来的键盘顺序和角色过滤，无需新增脚本。
- 页面标题使用浅色背景和轻量 CSS 图形，表单保持实色。系统中文字体和本地 CSS 减少额外网络请求，颜色与文字、粗体或边框共同表达状态。

## Risks / Trade-offs

- 窄屏长账号、路径、代码与列表可能撑开布局。按 390 和 1440 像素验证主要页面，并核对缩窄时导航和输入仍可访问。
- 浅色主题容易降低对比度。用浏览器读取实际文字/表面色，核对正文 4.5:1 和焦点轮廓，并抽查原有错误、空状态及禁用表现。

## Migration Plan

随既有应用镜像部署。需要回退时切换到上一版本镜像，沿用现有数据和配置。
