## Why

维护者需要知道本次测试走过哪些 API、哪些响应违反安全约束。仅凭 pytest 的通过数，无法回答具体路径的检查结果。

## What Changes

- 提供本地审查命令，枚举主应用和教学 MCP 服务的 API，观察仓库现有断网测试，按方法和路径报告风险、覆盖缺口和检查依据。
- 更新安全审查与接口回归记录，注明候选、实测和待复核项。

## Capabilities

纯工程测试工具，沿用现有 HTTP、授权与测试契约，使用 CLI 的工具变更例外。

## Impact

改动涉及开发脚本、单元测试与证据。采用本地 Flask 路由和测试客户端，放弃向部署环境逐个发送业务请求的方案，避免测试改变真实教学数据。
