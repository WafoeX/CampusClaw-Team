# 拒绝审计写入有界防护

## Why

学生越权配置请求在权限检查处返回 403，随后拒绝审计另开事务写库，未经过业务写配额。持续请求可能放大审计数据库写入，影响正常教学。用户需要在最终验收前修复该已知 P2 风险，并保留真实红绿证据。

## What Changes

- 对学生同源配置越权审计增加线程安全、单进程有界的固定窗口预算，保留原始 403 契约。
- 默认每主体每 60 秒最多 60 次、每应用进程总计最多 600 次审计写尝试；部署可通过统一配置调整正整数限额。
- 预算耗尽后不再开审计事务，每窗口至多一条去内容预算告警；每个请求仍有现有 HTTP 拒绝日志。失败写尝试也占预算。
- 增加并发、主体与总量、窗口、故障、输入及正常教学可用性的回归和隔离验证。

## Capabilities

### New Capabilities

- `denied-audit-budget`：限制越权配置请求的审计写入，保证失败关闭和可解释的事件覆盖边界。

### Modified Capabilities

无。候选任务审计及正常业务审计保持原契约。

## Impact

影响统一配置、应用装配、拒绝处理与操作审计服务，以及对应测试和字典。无新依赖、无表结构或业务 API 变化。当前部署固定单 worker；多个进程/副本的预算分别计算，不能作为分布式限流或完整抗拒绝服务结论。纯业务写入与成功审计不使用本预算。
