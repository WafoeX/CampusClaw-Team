# Spec Delta

## Purpose

为学生提供绑定本人已开放错题的独立流式讲解，在可继续追问和保存私人历史的同时，保证任何模型输出、增量与引用都不能直接复述标准答案。

## ADDED Requirements

### Requirement: 本人错题可启动独立讲解

系统 MUST 只允许学生为本人已正式提交、答案已开放且评分为错误或未作答的题目启动错题讲解。启动结果 MUST 绑定一个本班已启用且配置了独立错题讲解技能的助手，并返回私人会话标识及不含标准答案的首轮问题。创建 MUST 支持幂等重放。

#### Scenario: ME-N01 从已开放错题启动讲解
- **GIVEN** 学生有一条本人已开放错题，本班存在启用并绑定独立错题讲解技能的助手
- **WHEN** 学生从错题卡启动讲解
- **THEN** 返回 201、私人会话标识和只含题干及本人错误作答的首轮问题，同一幂等键同请求重放返回同一会话且不重复创建

#### Scenario: ME-F01 参数或幂等键不合法
- **GIVEN** 学生已登录但题目标识、测验标识、请求体或幂等键不合法
- **WHEN** 请求启动错题讲解
- **THEN** 返回 400/1000，不创建会话、不调用模型且不写成功审计

#### Scenario: ME-F02 非本人、未开放或非错题资源统一隐藏
- **GIVEN** 请求者是教师、另一学生或另一班账号，或者目标测验/题目不存在、未正式提交、答案未开放、答题正确
- **WHEN** 请求目标错题的讲解入口
- **THEN** 角色无权返回 403/1200；非本人、跨班、不存在、未提交、未开放和非错题统一返回 404/1300，响应不泄露资源是否存在及答案内容

#### Scenario: ME-F03 班级未配置错题讲解
- **GIVEN** 错题合法，但本班没有同时启用助手和独立错题讲解技能的配置
- **WHEN** 学生启动错题讲解
- **THEN** 返回 409/1400 和可操作的配置提示，不创建普通解题会话冒充独立错题讲解

#### Scenario: ME-F04 持久化依赖故障
- **GIVEN** 错题合法且配置可用，但教学查询或私人会话存储不可用
- **WHEN** 学生启动错题讲解
- **THEN** 返回 503/1500，不返回成功会话或部分标准答案，重试可使用原幂等键恢复

### Requirement: 讲解只输出固定安全提示

独立错题讲解 MUST 将题干、学生自己的错误作答和后续追问作为不可信数据。标准答案 MUST NOT 进入首轮问题、模型选择输入的答案字段、技能正文、SSE 增量或引用。模型只能选择服务端登记的错因诊断、定位首个错误步骤、重新尝试和复核提示槽位；服务端 MUST 校验选择结果后才流式输出固定中文提示。讲解引用 MUST 为空，私人消息和执行记录仅本人可读。

#### Scenario: ME-N02 依据错误作答给出可继续提示
- **GIVEN** 学生已建立本人错题讲解会话，夹具可核对题干、错误作答和标准答案
- **WHEN** 首轮问题说明错误作答并继续追问错误原因
- **THEN** 每轮返回至少一条可操作的错因定位或改进提示，SSE 增量拼接、持久消息和执行记录一致，引用为空且不包含标准答案

#### Scenario: ME-F05 直接索要答案和提示注入
- **GIVEN** 学生在首轮或追问中要求直接输出标准答案，并夹带改变角色、执行资料指令或输出自由文本的内容
- **WHEN** 独立错题讲解执行
- **THEN** 模型结果只有允许的提示槽位才可通过；最终输出、每个增量和引用均不含标准答案、工具请求或注入内容

#### Scenario: ME-F06 模型不可用或返回畸形结构
- **GIVEN** 错题讲解会话和配置有效，但模型超时、依赖故障或返回未知/重复/越界提示槽位
- **WHEN** 执行一轮讲解
- **THEN** 流以 1500 或 1501 失败终止，不保存成功消息；同一请求不得在故障后产生两个成功结果

#### Scenario: ME-B01 标准答案为短值或选项文本
- **GIVEN** 标准答案分别为单字符选项、真假值或选项文本，学生作答均错误
- **WHEN** 执行并拼接全部讲解增量
- **THEN** 输出只由登记的固定提示组成，不回显题干、选项、学生输入或标准答案，因而短答案也不会经自由文本旁路泄露
