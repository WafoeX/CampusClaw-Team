# Spec Delta

## Purpose

为候选题异步任务提供与业务状态一致的去内容审计，使教师能够在本班授权范围内按任务标识复核受理、重放和执行结果，同时保留用量缺失、依赖故障、到期清理与恢复的真实边界。

## ADDED Requirements

### Requirement: TJA-01 候选题任务事件可追溯

系统 MUST 在受理、获准重放和终态状态变更时追加去内容操作审计，关联任务标识、服务端班级与操作者、事件时间、动作、结果和耗时。模型实际返回有效 token 总数时记录用量；未提供或未调用模型时保留相应缺失状态，不推断为零。候选题不是技能，技能标识 MUST 为空。

#### Scenario: TJA-N01 正常受理并成功完成
- **GIVEN** 本班教师和已发布的授权证据可用，模型返回有效用量
- **WHEN** 教师受理候选题任务并轮询至成功
- **THEN** HTTP 202 的任务 ID 可关联受理与成功审计；两条记录显示同班操作者、实际时间、动作、任务 ID 和各自耗时，成功事件保留实际 token 总数，均不含题干、答案、证据正文或凭据

#### Scenario: TJA-B01 模型未提供用量
- **GIVEN** 模型成功生成候选题但响应缺少有效 token 总数
- **WHEN** 任务进入成功终态并查询其审计
- **THEN** 结果如实标记用量不可用且数值为空，不写零、不从输出长度估算，也不阻断可用的候选草稿

#### Scenario: TJA-F01 受理参数或来源无效
- **GIVEN** 教师已登录但提交非法题数、外班资料或未授权来源
- **WHEN** 请求候选题受理
- **THEN** 按原接口分别返回参数、资源或来源错误，不新增任务、发件箱或成功受理审计

### Requirement: TJA-02 审计与任务状态原子且幂等

系统 MUST 只为实际生效的受理、获准重放及终态写审计。任务状态与对应审计在同一业务事务提交；重复投递、过期租约和失败重放不得复制同一代次的终态事件，也不得覆盖较新的实际结果。

#### Scenario: TJA-N02 获准重放新代次
- **GIVEN** 本班教师拥有符合现有重放条件的失败任务
- **WHEN** 教师重放并使新代次进入成功终态
- **THEN** 原失败事件保留，新代次有独立重放和成功事件；任务与审计均可按同一任务 ID 追溯，生效候选题仍仅一批

#### Scenario: TJA-F02 重复消息与过期租约
- **GIVEN** 同一任务消息被重复投递或旧 worker 的租约已失效
- **WHEN** 重复消费者尝试结算
- **THEN** 仅当前生效代次产生一条终态审计，旧执行者不新增事件、不写候选题、不改最终状态

#### Scenario: TJA-F03 审计存储失败
- **GIVEN** 隔离环境在受理或终态审计写入点注入数据库故障
- **WHEN** 对应业务事务尝试提交
- **THEN** 该次任务与审计一起回滚或保持可重试的旧状态，不出现已受理或已结算却缺对应审计的记录；接口或 worker 明确暴露依赖故障，恢复后可重试

#### Scenario: TJA-F04 撤权或来源失效
- **GIVEN** 已受理任务的教师被撤权，或引用资料在执行前失效
- **WHEN** worker 按原授权和来源规则结算任务
- **THEN** 不发布候选题，任务按原契约取消或失败，终态审计记录实际结果与可用的耗时/用量，不包含被撤销的正文

### Requirement: TJA-03 本班授权查询与生命周期

教师 MUST 能以任务 ID 在现有操作审计列表中筛选本班有效事件。查询 MUST 使用当前数据库身份限定班级，学生不得读取，跨班与不存在的事件详情同构；到期与恢复遵守既有审计留存和清理规则，不复活已到期事件。

#### Scenario: TJA-N03 教师按任务查询
- **GIVEN** 本班任务已有受理和终态事件
- **WHEN** 本班教师以任务 ID 筛选操作审计并打开其中一条详情
- **THEN** 只返回该任务未过期的去内容事件，详情与列表字段一致，查询不推进任务状态或调用模型

#### Scenario: TJA-F05 学生或跨班读取
- **GIVEN** A 班任务与审计存在，B 班教师和 A 班学生知道任务或事件 ID
- **WHEN** 学生读取审计，B 班教师筛选任务或读取事件详情，并与不存在 ID 对照
- **THEN** 学生得到 403，B 班列表为空，跨班详情与不存在详情均为 404/1300 且公开内容同构，无 A 班元数据

#### Scenario: TJA-F06 任务标识格式错误
- **GIVEN** 教师已登录
- **WHEN** 用非法任务 ID 筛选审计
- **THEN** 返回受控 400 参数错误，不执行全班无过滤查询，也不暴露数据库异常

#### Scenario: TJA-B02 到期与恢复
- **GIVEN** 审计已到 90 天保留期限，隔离备份中仍有旧行
- **WHEN** 运行既有清理并在恢复后按原期限再次清理，再查询任务审计
- **THEN** 过期事件不可读且不会复活；业务任务自身按既有教学数据留存独立处理，不延长审计期限
