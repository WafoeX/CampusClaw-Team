# 安全技术自审二：浏览器回归失败输出

| 项目 | 实际记录 |
| --- | --- |
| 手段 | 复核隔离 Chromium 红灯运行的异常输出。在同一标题赋值故障下比较断言诊断、退出码和口令模式命中。 |
| 对象 | `tests/browser/run_teaching.py` 的容器启动参数和失败栈，规则 SEC-10、OPS-06、REV-07。 |
| 判据 | 断言仍以非零退出并保留诊断，输出不含合成测试口令。 |
| 发现 | Docker 命令参数带有合成口令值，浏览器用例失败时 Python 异常栈回显该参数。 |
| 处置与复测 | 两处合成口令改由子进程环境继承。原故障仍退出 1，断言差异保留，口令模式命中 0。恢复模板后整条浏览器回归退出 0。 |

执行于隔离 Docker、Chromium 与 MySQL。首轮诊断已脱敏，原始输出保留在工作区外。人工独立复验待项目最终验收。见[实测记录](../docs/changes/2026-11-04-remediate-security-findings.md#2026-11-16-浏览器测试口令脱敏sec-0563-取证)和[修复提交](https://github.com/WafoeX/CampusClaw-Team/commit/546a954)。
